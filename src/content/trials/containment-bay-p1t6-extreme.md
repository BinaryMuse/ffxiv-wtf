Extreme version of Sophia featuring the complex tilt/balance mechanic, Sin and Punishment spreads, and precise add management. The equilibrium mechanic defines this fight.

## Sophia

The Goddess returns with her signature balance mechanics demanding precise positioning and quick math to survive.

### Phase 1 - Opening (100% - 70%)

| Mechanic | Type | Description |
|----------|------|-------------|
| Thunder II | **Cleave** | Frontal cone with Electrocution DoT - tank faces away |
| Thunder III | **AoE** | Ring AoE - safe inside hitbox or far outside |
| Aero III | **Knockback** | Point-blank AoE with knockback - move away |
| Light Dew | **AoE** | Daughter (head) fires laser - dodge when she reappears |
| Arms of Wisdom | **Tankbuster** | Heavy physical damage - tank cooldowns |
| Cintamani | **Raidwide** | Room-wide damage - healers top off |
| Quasar | **AoE** | Proximity damage from center - run to edges |
| Onrush | **AoE** | Sophia charges from east/west - avoid the line |

**Notes:**
- Thunder III safe zones: directly under Sophia OR very far away
- Phase transition at ~70% with Cloudy Heavens

### Phase 2 - Tilt Mechanics (Scales of Balance)

| Mechanic | Type | Description |
|----------|------|-------------|
| Scales of Balance | **Mechanic** | Meteors and adds appear on scale platforms |
| Tethers | **Mechanic** | Tethers connect to scale - add weight to that side |
| Tilt | **Knockback** | Arena tilts based on weight - move to heavier side |

**Tilt Resolution Rules:**
1. **Always move to the side with MORE tethers**
2. If tether counts are equal, move OPPOSITE the blue meteor
3. **Even total** (meteors + tethers): Go all the way to the edge
4. **Odd total**: Stop about 1/4 of the way to the edge

**Notes:**
- Count quickly and call out positioning
- Failing tilt = sliding off the arena = death

### Phase 3 - Sin and Punishment

| Mechanic | Type | Description |
|----------|------|-------------|
| Sin | **Spread** | Orange markers - must not overlap with other Sin |
| Punishment | **Stack** | Blue markers - must not overlap with other Punishment |
| Opposite Requirement | **Mechanic** | Sin players can overlap with Punishment, but not same color |
| Quasar | **AoE** | Proximity AoE occurs during spreads |

**Notes:**
- Pre-assign positions: typically healers/tanks one side, DPS other
- Sin players spread from each other
- Punishment players spread from each other
- Sin can touch Punishment safely

### Phase 4 - Adds (Daughter/Barbelo)

| Mechanic | Type | Description |
|----------|------|-------------|
| Daughter | **Adds** | Must be killed - uses Light Dew laser |
| Barbelo | **Adds** | Second add - focus after Daughter |
| Execute | **Raidwide** | Sophia's enrage mechanic at low HP |

### Phase 5 - Final Phase

| Mechanic | Type | Description |
|----------|------|-------------|
| All Previous | - | Tilt, Sin/Punishment, and all mechanics cycle |
| Accelerated Pace | **Mechanic** | Mechanics happen faster |
| Enrage | **Enrage** | Hard enrage timer |

**Tips:**
- Practice tilt math before attempting - it's the key mechanic
- Set waymarks for Sin/Punishment positions
- Call out tilt direction for the party
- Pre-shield before Cintamani and tilt sequences
- Tanks should position Sophia center for consistent mechanic timing
