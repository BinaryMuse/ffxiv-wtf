The extreme version of the Shinryu trial, featuring complex platform management and primal-based mechanics across four phases.

## Shinryu

### Phase 1 (100% - 44%)

| Mechanic | Type | Description |
|----------|------|-------------|
| Auto-attack Lasers | **Tankbuster** | Main tank and off-tank take constant laser damage. Both tanks need to be ready. |
| The Worm's Heart | **Adds** / **Enrage** | Spawning add that must be killed quickly or causes massive AoE damage. |
| Earthen Fury | **Raidwide** / **AoE** | Raid-wide AoE that destroys mid-left and mid-right platforms. |
| Burning Chains | **Spread** | Players are chained together. Stack first, then separate to break chains. |
| Tidal Wave | **Knockback** | Run to water animation side to avoid being knocked off after breaking chains. |
| Tail Slam | **AoE** | Healer receives green marker. Bait the tail to a non-cracked platform to preserve front and middle. |
| Hypernova | **Stack** | Stack marker on a player from wing attacks. |
| Ice Storm | **AoE** | Wing attack causing area damage. |
| Levinbolt | **Spread** | Wing attack requiring players to spread. |
| Summon Icicle | **AoE** | Wing attack spawning icicles to avoid. |

**Notes:** Corrupted Aether abilities are random: Aerial Blast, Diamond Dust, Hellfire, Judgement Bolt, or Tidal Wave. Watch the gauge and prepare accordingly.

### Phase 2 (Add Phase)

| Mechanic | Type | Description |
|----------|------|-------------|
| Add Spawns | **Adds** | Adds spawn at arena corners. Tanks pick them up and bring to center for AoE damage. |

**Notes:** Defeat add waves quickly to return to Phase 1 mechanics before Phase 3 transition.

### Phase 3 (44% - 23%)

| Mechanic | Type | Description |
|----------|------|-------------|
| Active Time Maneuver | **Enrage** | All players must spam the button prompt to fill a bar. Failure = death during Phase 4 transition. |
| Protostar | **Raidwide** | Heavy raid-wide damage during transition. |

**Notes:** Phase 3 continues evolved Phase 1 mechanics with tighter execution.

### Phase 4 (23% - 0%)

| Mechanic | Type | Description |
|----------|------|-------------|
| Tail Slam | **AoE** / **Adds** | DPS must damage Shinryu's tail. Reducing tail to 0% inflicts 5% damage to Shinryu. |
| Platform Destruction | **AoE** | Platforms shatter after multiple hits, leaving holes in the arena. |
| Burning Chains | **Spread** | Orange circles indicate chains. Move toward partner to minimize chain size, then apart to break. |
| Akh Morn | **Tankbuster** | Off-tank stacks with main tank. Both use defensive cooldowns. |
| Corrupted Aether | **Raidwide** | When meter fills, one of five abilities casts based on element. |

**Corrupted Aether Types:**
- **Earth**: Ground AoE to avoid
- **Fire**: Massive damage—stand in water pools
- **Ice**: Icy floor causes sliding
- **Lightning**: Platform-wide damage
- **Wind**: Pushes toward edges

**Notes:** Tail is the primary damage source in this phase. Manage platform space carefully as tiles break.
