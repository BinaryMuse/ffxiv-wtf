The extreme version of the Hades trial. A significantly longer encounter than other Shadowbringers extreme trials, featuring multiple phases with complex mechanics and tight coordination requirements.

## Hades

### Phase 1

| Mechanic | Type | Description |
|----------|------|-------------|
| Ravenous Assault | **Tankbuster** | Heavy tankbuster requiring cooldowns and potential tank swaps. |
| Bad Faith | **AoE** | Walls with arrows—move to the safe side based on arrow direction. |
| Dark Eruption | **Spread** | Spread markers and ground AoEs. Don't overlap with other players. |
| Broken Faith | **AoE** | Falling disc markers creating explosion zones. |
| Shadow Spread | **AoE** | Boss-centered AoE patterns requiring movement. |
| Tether Mechanics | **AoE** | Various tethers require specific handling—some groups assign to DPS, others to tanks/healers. |

**Notes:** The first phase establishes the baseline mechanics. Execute cleanly to build momentum.

### Phase 2 (Add Phase)

| Mechanic | Type | Description |
|----------|------|-------------|
| Ancient Darkness | **Adds** | Waves of adds spawn with a doom timer. Must clear before gauge fills. |
| Spread/Stack Overlap | **Spread** / **Stack** | Mechanics overlap with add spawns. Prioritize positioning while DPSing adds. |
| Ancient Dark IV | **Enrage** | Gauge reaching 100% = wipe. |

**Notes:** Coordinate AoE cooldowns for efficient add clearing.

### Phase 3

| Mechanic | Type | Description |
|----------|------|-------------|
| Titanomachy | **Raidwide** | Heavy raid-wide damage requiring mitigation. |
| Shadowstream | **AoE** | Center line AoE—move to sides. |
| Dual Strike | **Tankbuster** | Hits both tanks—spread and mitigate. |
| Echo of the Lost | **Cleave** | One-sided cleave based on arm animation. |
| Polydegmon's Predation | **AoE** | Edge AoEs—move to center. |
| Captivity | **AoE** | Player-targeted circles. |

**Notes:** Phase 3 increases the pace. Mechanics come faster with less recovery time.

### Phase 4 (Final Phase)

| Mechanic | Type | Description |
|----------|------|-------------|
| Combined Mechanics | **AoE** | All previous mechanics overlap with minimal safe zones. |
| Increased Damage | **Raidwide** | Higher outgoing damage requires stronger healing and mitigation. |
| Enrage | **Enrage** | Must defeat Hades before the enrage timer. |

**Notes:** This is a longer fight than typical extreme trials. Maintain focus throughout and conserve resources for the final phase. The fight can be practiced via Stone, Sky, Sea for DPS checks.
