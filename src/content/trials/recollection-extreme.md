The extreme version of the Zelenia trial. Unlocked by speaking to the Wandering Minstrel in Tuliyollal after completing the normal trial.

## Zelenia

An enhanced version of Zelenia with additional mechanics, tighter timing, and an add phase requiring DPS coordination.

### Opening Phase

| Mechanic | Type | Description |
|----------|------|-------------|
| Thorned Catharsis | **Raidwide** | Heavy party-wide damage opening the fight |
| Shock + Towers | **Spread** | Four towers spawn in quadrants - large AoE targets go to towers, small baits spread away |

### Tank Mechanics

| Mechanic | Type | Description |
|----------|------|-------------|
| Specter of the Lost | **Tankbuster** | Tank tethers spawn - each tank grabs one and aims away from group with heavy mitigation |

### Escelons' Fall

| Mechanic | Type | Description |
|----------|------|-------------|
| Escelons' Fall | **Stack** | Four back-to-back cleaves targeting nearest or furthest players based on marker above boss |
| Positioning | **Mechanic** | Watch marker - supports and DPS alternate taking cleaves in clock positions |

### Stock Break

| Mechanic | Type | Description |
|----------|------|-------------|
| Stock Break | **Stack** | Four-hit split damage AoE - stack together and healers keep party healthy |

### Add Phase

| Mechanic | Type | Description |
|----------|------|-------------|
| Blessed Barricade | **Adds** | Boss becomes untargetable and summons four Roseblood adds |
| DPS Check | **Mechanic** | Kill adds before the Aether gauge fills or wipe |

### Clone Mechanics

| Mechanic | Type | Description |
|----------|------|-------------|
| Clone Spawns | **Mechanic** | Clones appear on arena sides with tethers to individual players |
| Clone Resolution | **AoE** | Dodge based on your tethered clone's position and attack |

**Tips:**
- Coordinate tank positions for Specter of the Lost tethers
- Assign clock positions for Escelons' Fall - know if you're near or far group
- Save DPS cooldowns for the add phase - the Aether gauge is unforgiving
- Communication is key for clone tethers
- Rewards item level 745 weapons and crafting materials
