Hard mode version of the Ifrit trial. An 8-player encounter that introduces more complex mechanics and the importance of interrupts.

## Ifrit

The Lord of the Inferno returns with enhanced abilities and new attacks.

### Phase 1 (100% - 75%)

| Mechanic | Type | Description |
|----------|------|-------------|
| Incinerate | **Cleave** | Frontal cone attack - tank faces Ifrit away from party |
| Vulcan Burst | **Knockback** | Instant PBAoE knockback - ranged stay at distance |
| Eruption | **AoE** | Cracks appear and explode - **interrupt with stuns** to prevent |
| Crimson Cyclone | **AoE** | Ifrit jumps to edge then charges across - stay to his sides |

**Notes:**
- Interrupting Eruption is critical throughout the entire fight
- Eruptions become increasingly difficult to dodge in later phases

### Phase 2 (75% - 50%)

| Mechanic | Type | Description |
|----------|------|-------------|
| Sear | **AoE** | Instant PBAoE similar to Vulcan Burst - stay at range |
| Radiant Plume | **AoE** | Red circles on ground - patterns alternate between outer and inner rings |
| All Phase 1 | - | All previous mechanics continue |

**Notes:**
- When Radiant Plume appears, run to center then back out as patterns change
- Keep interrupting Eruptions

### Phase 3 (50% - 0%)

| Mechanic | Type | Description |
|----------|------|-------------|
| Infernal Nails | **Adds** | Four nails spawn in diamond formation - destroy before Hellfire |
| Hellfire | **Enrage** | Kills party if nails survive |
| Crimson Cyclone x3 | **AoE** | Three clones charge - standing between two clones is safe |
| Eruption (Enhanced) | **AoE** | Covers ~80% of arena if not interrupted |

**Tips:**
- Use caster Limit Break on nails if needed
- Continue interrupting Eruption - it's the top priority
- Watch for safe spots between Crimson Cyclone clones
