The Extreme version of the Ramuh trial. An 8-player encounter centered around orb management and precise execution of the Chaotic Strike save mechanic.

## Ramuh

Ramuh remains stationary in the center and has no cleave attacks. The fight revolves around lightning orb management.

### Orb Mechanics

| Buff | Orb Count | Effect |
|------|-----------|--------|
| Electroconductivity | Exactly 3 | Required for tanks to survive Shock Strike |
| Overcharge | 4+ orbs | Reduces healing received (stacks up to 3x) |

**Critical:** Leave orbs on the ground for saves and tether breaks.

### Phase 1 (100% - 64%)

| Mechanic | Type | Description |
|----------|------|-------------|
| Thunderstorm | **AoE** | AoEs on players - some stationary, spawn orbs when exploding |
| Thunderspark | **AoE** | PBAoE on Ramuh - move away during cast |
| Shock Strike | **Tankbuster** | Requires 3 Electroconductivity stacks or instant death |
| Chaotic Strike | **AoE** | Two non-tanks get Terror - walk toward Ramuh, stunned |

**Chaotic Strike Save:** Player with active Thunderstorm (circle outline) must stand near Terrored player to shock them free. Set a waymark behind Ramuh as the save point.

### Tank Swap Pattern

1. Off-tank collects 3 orbs after every other Thunderstorm
2. Off-tank provokes to swap
3. Repeat throughout fight

### Phase 2: Add Phase (64% HP)

| Mechanic | Type | Description |
|----------|------|-------------|
| Grey Arbiters | **Adds** | Six adds spawn in a circle |
| Judgement Bolt | **Enrage** | Kills party if any adds survive |

**Strategy:** Kill all adds before Judgement Bolt completes. Previous mechanics continue during this phase.

### Phase 3 (64% - 30%)

| Mechanic | Type | Description |
|----------|------|-------------|
| Rolling Thunder | **AoE** | Two players tethered by lightning |
| All Phase 1 | - | All previous mechanics continue |

**Rolling Thunder:** One tethered player collects 3 orbs to break the chain.

### Phase 4 (30% - 0%)

| Mechanic | Type | Description |
|----------|------|-------------|
| Bat Phase | **Adds** | Bats spawn - handle while continuing mechanics |
| Increased intensity | - | Faster ability rotations |

**Tips:**
- Orb management is the key to this fight
- Tanks swap after every Shock Strike
- Never collect 4+ orbs - healing reduction is brutal
- Save designated players for Chaotic Strike rescues
- Grey Arbiters must all die before Judgement Bolt
- Rolling Thunder tethers require 3 orbs to break
