The extreme version of the Monster Hunter Wilds crossover trial. An enhanced encounter with tighter mechanics and additional attack patterns.

## Guardian Arkveld

A more challenging version of Guardian Arkveld with no death limit but punishing mechanics. Like the normal version, **no cast bars** are used - watch animations carefully.

### Opening Phase

| Mechanic | Type | Description |
|----------|------|-------------|
| Side Swipe Combo | **Cleave** | Two-hit cleave pattern - dodge center hit, then move opposite side for second |
| Crack Patterns | **AoE** | White cracks = sides safe (middle dangerous), Red cracks = middle safe (sides dangerous) |
| Light Party Stacks | **Stack** | Groups position near and far from boss jump locations during cracks |

### Core Mechanics (Enhanced)

| Mechanic | Type | Description |
|----------|------|-------------|
| Roar | **Raidwide** | Heavy party damage requiring mitigation and healing |
| Chainblade Blow | **Cleave** | Boss raises arm, half-room cleave then ground AoE - move opposite |
| Wyvern's Siegeflight | **Cleave** | Charge across arena with red/white crack patterns determining safe zones |
| Rush | **AoE** | Three red line charges - walk into one and dodge expanding rings |

### Devour Pattern

| Mechanic | Type | Description |
|----------|------|-------------|
| Devour AoE | **AoE** | Stand near third circle from center, then move into it when boss arrives |

### Tower Phase (Enhanced)

| Mechanic | Type | Description |
|----------|------|-------------|
| Puddle Baits | **AoE** | Bait puddles before towers spawn |
| Small Towers | **Soak** | Cardinal position towers requiring soaks |
| Large Tank Towers | **Tankbuster** | Two large towers requiring tank mitigation before soaking |
| Exaflares | **AoE** | Move outward from center after soaking towers |
| Crystal Explosions | **AoE** | Avoid crystals - they explode on contact |

### Chainblade Charge

| Mechanic | Type | Description |
|----------|------|-------------|
| Chainblade Charge | **Stack** | Stack marker on healer - requires group coordination |

**Tips:**
- Master reading animations - no cast bars means visual tells are everything
- Remember: Red = middle safe, White = sides safe
- Coordinate light party positions during crack phases
- Tanks must use strong cooldowns before soaking large towers
- Avoid crystals during exaflare movement
- Rewards Veldian Weapon Coffer (ilvl 745) and Guardian Arkveld Certificates
- Carve Arkveld's head for 4 Guardian Scales
