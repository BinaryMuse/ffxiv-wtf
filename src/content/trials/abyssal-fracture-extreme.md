The Abyssal Fracture (Extreme) is the final Extreme trial of the Endwalker expansion, featuring Zeromus, a Voidsent created from Azdaja's aether. The fight requires precise debuff management and has a 60-minute time limit.

## Zeromus

### Pre-Fight Setup

Organize into two light parties with designated corner assignments: ranged/healer pairs to Southwest/Southeast, melee/tank pairs to Northwest/Northeast.

### Phase 1 - Opening

| Mechanic | Type | Description |
|----------|------|-------------|
| Abyssal Nox | **Raidwide** | Sets all party members to 1 HP and applies a 20-second Doom debuff. Cleanse by healing to full HP while dodging purple light ray circle AoEs. |
| Sable Thread | **Stack** | Line stack marker on a random player. Group up and heal through multiple damage hits. |
| Visceral Whirl | **AoE** | Two perpendicular line AoEs with safe spots in opposing corners. Move to a safe corner quickly. |
| Dark Matter | **Tankbuster** | Heavy tank buster on main tank. Use defensive cooldowns and face away from party. |
| Flare | **Stack** | Pillar appears with stack marker. Group to split damage, then dodge the follow-up line AoEs from the fireball. |
| Void Bio | **AoE** | Orbs slowly move across the arena. Dodge while handling other mechanics. |
| Nox | **AoE** | Chasing AoE on a random player. Keep moving to avoid damage. |

### Phase 2 - Big Bang

| Mechanic | Type | Description |
|----------|------|-------------|
| Big Bang | **Raidwide** | Massive raidwide that reduces max HP and applies debuffs. Heavy mitigation required. |
| Acceleration Bomb | **AoE** | Debuff requiring players to stop ALL actions (including movement and auto-attacks) when it expires, or take heavy damage. |
| Divisive Dark | **AoE** | Debuff that must be resolved alongside other mechanics. Position carefully. |

### Phase 3 - Meteor Impact

| Mechanic | Type | Description |
|----------|------|-------------|
| Meteor Impact | **AoE** | Large meteors drop with impact zones. Identify safe areas between impacts. |
| Black Hole | **AoE** | Creates zones that pull players. Position against the pull direction. |
| Big Crunch | **Raidwide** | Heavy raidwide damage following Black Hole. |

### Phase 4 - Advanced Mechanics

| Mechanic | Type | Description |
|----------|------|-------------|
| Sparking Flare | **Spread** | Spread version of Flare mechanic. Move to assigned positions. |
| Branding Flare | **Stack** | Stack version requiring light party stacks. |
| Rend the Rift | **AoE** | Phase transition with heavy arena-wide damage. |
| Nostalgia | **Raidwide** | Replays previous mechanics in sequence. Remember earlier patterns. |
| Flow of the Abyss | **AoE** | Line AoEs that flow across the arena in patterns. Track and dodge. |
| Chasmic Nails | **AoE** | Ground-targeted AoEs that must be avoided during other mechanics. |

### Phase 5 - Enrage

| Mechanic | Type | Description |
|----------|------|-------------|
| Dimensional Surge | **Raidwide** | Escalating raidwide damage as enrage approaches. |
| The Last Gasp | **Enrage** | Hard enrage. Must defeat Zeromus before this resolves. |

**Notes:**
- Arena has no borders—falling off is instant death (resurrection possible).
- Abyssal Nox is the first major heal check—healers must quickly restore everyone to full to cleanse Doom.
- For Acceleration Bomb: STOP EVERYTHING when the debuff timer expires. Any action triggers the explosion.
- Coordinate corner assignments before pull to handle Visceral Whirl cleanly.
- Big Bang significantly reduces healing received—plan mitigation accordingly.
