The Voidcast Dais (Extreme) is the Extreme version of the Golbez trial, unlocked by speaking to the Wandering Minstrel in Old Sharlayan after completing the 6.4 MSQ "Abyssal Dark." The fight has an 11:00 hard enrage and requires approximately 56,400 raid DPS to clear.

## Golbez

### Pre-Fight Setup

Assign clock positions: tanks North/South, healers East/West, DPS on intercardinals. Split into two light parties (1 tank, 1 healer, 2 DPS each).

### Phase 1 - Opening

| Mechanic | Type | Description |
|----------|------|-------------|
| Terrastorm | **AoE** | Two spheres move toward opposite intercardinal edges, creating circular AoEs covering roughly half the arena. Find the safe half. |
| Lingering Spark | **AoE** | Invisible AoEs placed under all players. Bait together in one spot, then move away as a group. |
| Binding Cold | **Raidwide** | Raidwide damage with a frost DoT. Heal through the sustained damage. |
| Void Meteor | **Tankbuster** | Tank buster hitting both tanks with four moderate hits followed by one heavy magical hit. Both tanks stack with cooldowns. |
| Phases of the Blade | **Cleave** | Sequential 180-degree cleaves—first in front of Golbez, then behind after a short delay. Start behind him, then move in front after the first cleave. |

### Phase 2 - Gale Sphere

| Mechanic | Type | Description |
|----------|------|-------------|
| Gale Sphere | **AoE** | Phantoms appear at cardinal edges and create line AoEs across the arena. Dodge by standing in a row or column without spheres. Watch the order phantoms appear to predict the sequence. |
| Arctic Assault | **AoE** | Icicle walls point in a direction, creating line AoEs covering two arena quadrants. Move to the safe quadrants. |
| Azdaja's Shadow | **Raidwide** | Transition raidwide damage. Mitigate and heal. |

### Phase 3 - Enhanced Mechanics

| Mechanic | Type | Description |
|----------|------|-------------|
| Black Fang | **Raidwide** | Multiple moderate damage hits followed by a heavy raidwide hit. Layer mitigation across all hits. |
| Double Meteor | **Tankbuster** | Enhanced Void Meteor with additional hits. Both tanks must use strong cooldowns. |
| Eventide Fall | **AoE** | Complex AoE pattern requiring precise positioning. |
| Eventide Triad | **AoE** | Triple AoE pattern with overlapping safe zones. |

### Phase 4 - Combinations

| Mechanic | Type | Description |
|----------|------|-------------|
| Gale Sphere 2 | **AoE** | More complex Gale Sphere patterns with additional overlapping mechanics. |
| Terrastorm + Mechanics | **AoE** | Terrastorm combined with other mechanics requiring multi-layered dodging. |
| Enrage | **Enrage** | Hard enrage at 11:00. Boss must be defeated before this point. |

**Notes:**
- The arena has no railings—falling off is instant death (resurrection possible).
- For Phases of the Blade: behind → front. Don't move too early.
- Gale Sphere sequence follows the order phantoms appeared—memorize the pattern.
- Coordinate Lingering Spark baits—the entire party should move together.
- Save heavy mitigation for Black Fang as it deals significant sustained damage.
