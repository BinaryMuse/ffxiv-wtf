The extreme version of the Titania trial featuring four phases with overlapping mechanics and tighter execution requirements.

## Titania

### Phase 1

| Mechanic | Type | Description |
|----------|------|-------------|
| Bright Sabbath | **Raidwide** | Unavoidable raid-wide AoE to open the fight. |
| Phantom Rune | **AoE** | In/out mechanic. Wings spread = circle AoE (run out), staff spinning = donut AoE (run in). Phase 1 is always circle then donut; later phases are random. |
| Mist Rune | **AoE** | Eight puddles spawn. Pre-assign positions—one player per puddle. Standing in puddle prevents add spawn and grants Fire Resistance Up. |
| Flame Rune | **Stack** | Two healers get stack markers. Split into 2x4 groups in West/East puddles. Fire Resistance Down II applied—don't stack both markers together. |
| Divination Rune | **Tankbuster** | Massive conal tankbuster. Tank must face boss away from party at all times. |
| Chain of Brambles | **Spread** | Tanks/healers tethered to DPS. Run to opposite corners (T/H north, DPS south) to break tethers. |

**Notes:** Pre-assign cardinal/intercardinal positions for puddles. Breaking brambles too slowly will cause damage and bind.

### Phase 2 (Forest Arena)

| Mechanic | Type | Description |
|----------|------|-------------|
| Thunder Rune | **AoE** | Tether creates repeated AoE blasts with Lightning Resistance Down II. Pass tether between players or use tank invulnerability for 2-3 hits. |
| Fae Light | **Tankbuster** | Triple-cast conal tankbuster in quick succession. Tanks can swap between casts or use invuln. |
| Growth Rune | **AoE** | Corners marked with star-pattern AoEs. Brambles grow in cardinal/diagonal lines, leaving small triangular safe spots. |
| Growth Rune + Brambles | **AoE** | Growth Rune and Chain of Brambles overlap. Break tethers while positioning in safe spots. |
| Frost Rune | **AoE** | Circles spawn and explode in order (center first, then clockwise/counter-clockwise around edges). Stand in late-spawning circles, then move to center. |
| Uplift | **Spread** | All players marked with spread AoE circles. Spread around arena to avoid overlapping. |
| Phantom Rune | **AoE** | Random in/out—watch animation carefully. |

**Notes:** Thunder Rune requires coordination. Assign tether order or have tanks with invuln take multiple hits.

### Phase 3 (Add Phase)

| Mechanic | Type | Description |
|----------|------|-------------|
| Mustardseed | **Adds** | Must die first or wipes raid with Whispering Wind. Casts Leafstorm (conal AoE with safe lines). |
| Puck | **Adds** | Casts Pummel (tankbuster), Puck's Breath (stack), Puck's Caprice (raidwide), Gentle Breeze (line AoE). |
| Peaseblossom | **Adds** | Casts Peasebomb (spread markers) and Hard Swing (tankbuster). |
| Puck's Rebuke | **Knockback** | Central circle with knockback. **Do not stand in circle or instant death.** Stand at edge to be knocked away. Combined with bramble tethers—position to break tethers via knockback. |
| Being Mortal | **Enrage** | If Titania's power gauge reaches 100%, raid wipes. |

**Notes:** Kill order: Mustardseed → focus both remaining adds. Giant versions spawn after first set dies—same mechanics but larger and more dangerous.

### Phase 4

| Mechanic | Type | Description |
|----------|------|-------------|
| Mist Rune + Phantom Rune | **AoE** | Combined puddles and in/out mechanic. |
| Flame Rune + Growth Rune | **AoE** | Stack in puddles while avoiding bramble growth patterns. |
| Phantom Rune | **AoE** | Random in/out. |
| Bright Sabbath | **Raidwide** | Heavy raid damage between mechanics. |
| Fae Light | **Tankbuster** | Triple conal—tank swap or invuln. |
| Frost Rune | **AoE** | Same as Phase 2—follow circle spawn order. |
| Uplift | **Spread** | Spread for AoE circles. |
| Thunder Rune | **AoE** | Tether mechanic returns. |
| Growth Rune + Brambles | **AoE** | Another overlap of growth and tethers. |
| Divination Rune | **Tankbuster** | Final tankbuster before enrage. |
| Bright Sabbath (Enrage) | **Enrage** | Must kill Titania before this cast completes. |

**Notes:** Phase 4 combines all mechanics from earlier phases. Maintain focus and execute cleanly to beat the enrage timer.
