The extreme version of the Seiryu trial, featuring tight tank swap mechanics and complex sigil-based positioning.

## Seiryu

### Phase 1

| Mechanic | Type | Description |
|----------|------|-------------|
| Fifth Element | **Raidwide** | Raid-wide AoE damage. Healers prepare. |
| Cursekeeper | **Tankbuster** | Places a barrier on the main tank that explodes as AoE damage later based on damage taken. **Requires a tank swap.** Paladin can use Cover on MT. |
| Infirm Soul | **Tankbuster** | Tankbuster immediately after Cursekeeper. Main tank uses cooldowns. |
| Kuji-Kiri | **Spread** / **AoE** | Four AoEs on random players with water vulnerability debuff, plus intersecting line AoEs across the arena. Spread and dodge. |
| Serpent Descending | **Spread** | Circle AoE markers on players. Spread to avoid overlapping damage. |
| Forbidden Arts | **Stack** | Line stack marker that fires twice. Stack with the marked player. |

**Notes:** Tank swap timing on Cursekeeper is critical. The barrier explosion damage scales with damage taken.

### Sigil Mechanics

| Mechanic | Type | Description |
|----------|------|-------------|
| Yin-Yang Symbol | **AoE** | AoE near boss. **Move away** from Seiryu. Watch for animation (no cast bar). |
| Dragon Symbol | **AoE** | Donut AoE. **Move close** to Seiryu. Watch for animation (no cast bar). |

**Notes:** These attacks have no cast bar—watch for visual animations around the boss to identify which is coming.

### Adds Phase

| Mechanic | Type | Description |
|----------|------|-------------|
| Red Wheels | **Adds** | Two Red Wheels spawn and tether to 2 players. They perform line AoEs—position carefully. |
| Summon Shiki | **Adds** | Additional minions spawn in a fixed sequence. |

**Notes:** Handle adds while continuing to respect sigil mechanics.

### Phase 2

| Mechanic | Type | Description |
|----------|------|-------------|
| Blazing Aramitama | **AoE** | Arena-wide mechanic requiring specific positioning. |
| Serpent Ascending | **AoE** | Seiryu performs large-scale attacks. Watch for safe zones. |
| Blue Bolt | **AoE** | Lightning-based attacks requiring spread or movement. |

**Notes:** Phase 2 continues Phase 1 mechanics with increased complexity. Maintain tank swap discipline and sigil awareness.
