Extreme version of the Ravana fight with tightened DPS checks, enhanced mechanics, and stricter parry timing. Use Party Finder for this content.

## Ravana

The Lord of the Hive returns with deadlier versions of his signature mechanics and a more punishing Bloodlust phase.

### Phase 1 - Opening (100% - 60% Bloodlust)

| Mechanic | Type | Description |
|----------|------|-------------|
| Seeing Wing | **Mechanic** | Parries attacks from sides - attack from front/back or take reflected damage |
| Seeing Tail | **Mechanic** | Parries attacks from front/back - attack from sides or take reflected damage |
| Blinding Blade | **Tankbuster** | Heavy physical damage with Bleed - tank swap or heavy cooldowns |
| Atma-Linga | **AoE** | Four orbs spawn and explode - dodge the marked areas |
| Prelude to Slaughter | **AoE** | PBAoE → line AoEs → donut AoE - move out, find gaps, move in |
| Slaughter | **AoE** | Cross-pattern lines with marked players - spread to corners, avoid overlapping |

**Notes:**
- Reflected damage from Seeing buffs is significant - always check which buff is active
- Blinding Blade's Bleed requires immediate tank swap or invulnerability

### Phase 2 - First Liberation (Swords)

| Mechanic | Type | Description |
|----------|------|-------------|
| Liberation | **Mechanic** | Ravana draws swords - signals new attack patterns |
| Swift Liberation | **Cleave** | Fast frontal cone - stay behind |
| Final Liberation | **Raidwide** | Room-wide damage - heal through |

### Phase 3 - Gana Phase (60% Bloodlust)

| Mechanic | Type | Description |
|----------|------|-------------|
| Moon Gana | **Adds** | **Kill these first** - each survivor adds swords to Bloody Fuller |
| Spirit Gana | **Adds** | Kill after Moon Ganas - also adds swords if alive too long |
| Falling Laughter | **Enrage** | Cast if adds survive - spawns maximum swords |
| Bloody Fuller | **Raidwide** | Party lifted and attacked - damage scales with sword count |

**Notes:**
- This is a strict DPS check - Moon Ganas must die quickly
- 4+ swords during Bloody Fuller is typically fatal
- Save cooldowns for add burst

### Phase 4 - Pillars and Warlord (Post-Gana)

| Mechanic | Type | Description |
|----------|------|-------------|
| Pillars of Heaven | **Knockback** | Knockback from center - position away from fence gaps |
| Surpanakha | **Tankbuster** | Four-hit combo on second-highest enmity - heavy cooldowns required |
| Warlord Shell | **Mechanic** | Ravana gains damage shield - must break before next phase |

**Notes:**
- Off-tank should use invulnerability or heavy mitigation for Surpanakha
- Breaking Warlord Shell is a DPS check

### Phase 5 - Second Gana Phase

| Mechanic | Type | Description |
|----------|------|-------------|
| Enhanced Ganas | **Adds** | More adds spawn with higher HP |
| Chandrahas | **AoE** | Ravana throws swords creating line AoEs - dodge between swords |
| Bloody Fuller | **Raidwide** | Second Bloody Fuller - must have killed adds efficiently |

### Phase 6 - Final Phase

| Mechanic | Type | Description |
|----------|------|-------------|
| All Previous | - | All mechanics cycle with tighter timing |
| Enrage | **Enrage** | Soft enrage if fight takes too long |

**Tips:**
- Pre-assign positions for Slaughter spreads
- Tank swap on every Blinding Blade
- Save Limit Break for Gana phases if DPS is struggling
- Practice Seeing Wing/Tail awareness - reflected damage adds up
