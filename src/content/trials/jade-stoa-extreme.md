The extreme version of the Byakko trial, featuring two phases with an intermission. Considered one of the easier Stormblood extreme trials.

## Byakko

### Setup

- Organize into two Light Parties of four players each
- Place three markers at different arena corners in a triangle formation
- Being hit by avoidable attacks applies Vulnerability Up (2 minutes)—minimize mistakes

### Phase 1

| Mechanic | Type | Description |
|----------|------|-------------|
| Storm Pulse | **Raidwide** | Raidwide AoE damage hitting twice. Repeated throughout the fight. |
| Heavenly Strike | **Tankbuster** | Single-target tankbuster requiring mitigation. |
| State of Shock | **Stack** | Byakko grabs the main target and throws them to a stack AoE. Light Party members stack to soak. |
| Highest Stakes | **Stack** | Same as State of Shock. **No player can stack twice or they die instantly.** Tanks can use invulnerability to skip. |
| Unrelenting Anguish | **AoE** | Byakko jumps to center, shooting rotating energy orbs. Avoid orbs or receive vulnerability debuffs. |
| Tiger Add | **Adds** | Tiger spawns. Two players receive orange markers and drop bleed puddles. Focus DPS on the add. |
| Healing Orbs | **Adds** | Orbs spawn that heal Byakko if they reach the tiger. Intercept or kill them. |

**Notes:** Tanks should keep stances on to be targeted for State of Shock/Highest Stakes.

### Intermission

| Mechanic | Type | Description |
|----------|------|-------------|
| Falling Phase | **AoE** | Players fall from the sky dodging donut AoEs. Safe zone is in Byakko's hitbox. |
| Red Bubbles | **AoE** | Avoid red bubbles while falling. |

**Notes:** When unsynced, possible to skip by holding DPS at 62% until Byakko jumps for orbs.

### Phase 2

| Mechanic | Type | Description |
|----------|------|-------------|
| Sweep the Leg | **Cleave** | 270-degree AoE. Move behind Byakko to avoid damage. |
| Exaflare-style AoEs | **AoE** | Four AoE markers with four additional markers spawning between them. Wait for first set to land twice before repositioning. |
| Tornado Placement | **AoE** | During Unrelenting Anguish, three players place tornados at cardinal positions (N, SE, SW). |
| Tornado Explosion | **Raidwide** | Tornados grow and explode if they intersect, applying vulnerability debuffs. Keep them separated. |

**Notes:** Phase 2 incorporates all Phase 1 mechanics with these additions. Proper tornado placement is critical.
