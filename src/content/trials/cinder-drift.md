The first trial of the Sorrow of Werlyt questline, pitting you against the Ruby Weapon—a Garlean warmachina inspired by the iconic boss from Final Fantasy VII.

## Ruby Weapon

### Phase 1

| Mechanic | Type | Description |
|----------|------|-------------|
| Stamp | **Tankbuster** | Standard tankbuster attack. Use mitigation cooldowns. |
| Optimized Ultima | **Raidwide** | Powerful raid-wide AoE. Healers prepare group heals. |
| Flexiclaw | **AoE** | Extended claw attack that initiates follow-up mechanics. |
| Ravensclaw | **AoE** | Tremor lines extend from Ruby Weapon with circular AoEs at their ends. Dodge the initial AoEs along the tremor lines. |
| Liquefaction | **AoE** | Ground sinks except on tremor lines. Stand ON the tremor lines to survive. |
| Undermine | **AoE** | Opposite of Liquefaction—tremor lines explode. Avoid tremor lines and stand between them. |
| Helicoclaw | **AoE** | Spiral AoE pattern. Position at the end of one spiral, let blasts pass, then run toward Ruby Weapon. |
| Ruby Dynamics | **Stack** | Run to Ruby Weapon, then split into two groups for Homing Lasers stack markers. |
| Ravensflight | **AoE** | Ruby Weapon dashes across the arena in patterns. Find safe spots from initial dashes, then reposition. Final dash typically goes through the middle. |

**Notes:** For Liquefaction, stand on cracks. For Undermine, avoid cracks. Watch the cast bar to know which is coming.

### Phase 2 (Nael Phase)

| Mechanic | Type | Description |
|----------|------|-------------|
| Phase Transition | **AoE** | Arena changes. If you wipe after this point, you restart from Phase 2. |
| Nael Mechanics | **AoE** | Ruby Weapon channels Nael Deus Darnus abilities from Binding Coil. |
| Meteor Phase | **AoE** | Comets and meteors must be handled with proper positioning. |
| Add Phase | **Adds** | Nael-themed adds spawn and must be defeated. |

**Notes:** The phase transition serves as a checkpoint. Phase 2 introduces Binding Coil references with Nael mechanics.
