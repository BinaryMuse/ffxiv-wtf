The extreme version of the Susano trial, featuring tighter mechanics and a required tank swap in Phase 3.

## Susano

### Phase 1

| Mechanic | Type | Description |
|----------|------|-------------|
| Assail | **Tankbuster** | Moderate damage tankbuster with no telegraph. Cast after each set of mechanics. |
| Churning | **AoE** | Four players receive a Churn debuff (10 seconds). At 3 seconds remaining, dice markers appear—**STOP moving and attacking** or receive Lightning Resist Down. |
| Rasen Kaikyo | **AoE** | All players drop puddles where they stand. Move away immediately to avoid damage and debuffs. |
| Brightstorm | **Knockback** / **Stack** | Orange marker player is knocked back, then targeted with a stack marker. Return to group. Arena-wide AoE follows with thin column safe zone. |
| Thunderhead | **AoE** | Column AoEs from arena edges target a player. Bait them away from the group. |

**Notes:** Tank the boss in the center. This is a single-tank phase with the group stacking behind the boss.

### Phase 2

| Mechanic | Type | Description |
|----------|------|-------------|
| Blade Shadow | **Adds** / **Enrage** | Main tank clicks the white marker and button-mashes to shield the raid. DPS must burn down the giant sword to prevent a wipe. |
| Shock Orbs | **AoE** | Off-tank soaks orbs with healer support while using Sprint and mitigation. |
| Tank Swap | **Tankbuster** | Tanks swap positions after each Blade Shadow phase. |

**Notes:** Group stacks mid. The off-tank soaking orbs is critical—coordinate with healers.

### Phase 3

| Mechanic | Type | Description |
|----------|------|-------------|
| Stormsplitter | **Tankbuster** | Heavy tankbuster requiring a tank swap after each cast. |
| Levin Bolt | **Spread** | Purple marker—run to the opposite side of a black line that appears. |
| Parting Clouds | **AoE** | Red marker—locate the storm cloud and move perpendicular to it. Move East/West if cloud is North/South; move South if cloud is East/West. |
| Churn | **AoE** | Same as Phase 1—stop moving when dice markers appear (3 seconds left). |
| Brightstorm | **Knockback** / **Stack** | Same as Phase 1 but with tighter execution required. |

**Notes:** Group stacks on the west side of mid. Main tank picks up boss and brings it north (slightly west or east, not directly north). Tank swaps are mandatory after Stormsplitter.
