Face Ramuh, the Lord of Levin, in this 8-player trial that introduces the unique orb collection mechanic.

## Ramuh

The Lord of Levin, primal of the Sylph beast tribe. Unlike other primals, Ramuh remains stationary in the center and has no cleave attacks.

### Orb Mechanics

| Mechanic | Type | Description |
|----------|------|-------------|
| Lightning Orbs | - | Appear throughout fight - collect exactly 3 for Electroconductivity buff |
| Electroconductivity | - | 3-orb buff reduces damage from Shock Strike |
| Static Condensation | - | 4+ orbs causes healing reduction debuff - avoid overcollecting |

**Critical:** Leave some orbs on the ground - they're needed for Chaotic Strike saves.

### Phase 1

| Mechanic | Type | Description |
|----------|------|-------------|
| Thunderstorm | **AoE** | AoE circles on random players - some remain stationary and spawn orbs |
| Thunderspark | **AoE** | Circular AoE centered on Ramuh - move away when cast begins |
| Shock Strike | **Tankbuster** | Targets main tank - 3 stacks of Electroconductivity mitigates damage |
| Chaotic Strike | **AoE** | Two random players receive Terror (40s stun) - save them with Thunderstorm |

**Saving Terrored Players:** A player with an active Thunderstorm (circle outline) must stand near the affected player to shock them free.

### Phase 2 (60% HP)

| Mechanic | Type | Description |
|----------|------|-------------|
| Grey Arbiters | **Adds** | Three adds spawn - must kill before Judgement Bolt |
| Judgement Bolt | **Enrage** | Wipes party if any adds survive |
| Rolling Thunder | **AoE** | Two players tethered - collect 3 orbs to break the tether |

**Tips:**
- Tanks should collect 3 orbs and swap after Shock Strike
- Don't hoard orbs - leave them for Terror saves and tether breaks
- Kill all Grey Arbiters before Judgement Bolt completes
- You can attack Ramuh from any angle - no positional requirements
