The Extreme version of the Garuda trial. An 8-player encounter with complex add management and multiple phases. One of the original "big three" ARR Extreme trials.

## Garuda

### Phase 1 (100% - ~75%)

| Mechanic | Type | Description |
|----------|------|-------------|
| Downburst | **Cleave** | Frontal cleave - tank faces away from party |
| Friction | **AoE** | Hits random player and nearby allies/boulders |
| Wicked Wheel | **AoE** | Instant circle AoE around Garuda |
| Eye of the Storm | **AoE** | Donut AoE in outer ring - stay toward center |
| Mistral Song | **Cleave** | Column AoE - hide behind boulder to break line-of-sight |

**Notes:** First 20 seconds are mechanic-free for opening DPS.

### Phase 2 (First Add Phase)

| Mechanic | Type | Description |
|----------|------|-------------|
| Chirada & Suparna | **Adds** | Two adds spawn with Garuda |
| Satin Plume | **Adds** | Kill first - prevents raid-wide sleep |
| Reckoning | **Enrage** | Wipes if any boulders are destroyed or adds survive |

**Strategy:**
- Tanks separate Chirada and Suparna
- Kill Satin Plume immediately
- All adds must die before Reckoning cast completes

### Phase 3 (Second Add Phase)

| Mechanic | Type | Description |
|----------|------|-------------|
| Spiny Plume | **Adds** | Builds stacking debuffs on tank - provoke to manage |
| Mistral Shriek | **Raidwide** | Wipes party unless inside Spiny Plume's protective dome |

**Critical Mechanic:** Kill the Spiny Plume ONLY when Garuda begins casting Shriek, then immediately enter the protective dome it creates.

### Phase 4 (Final Phase)

| Mechanic | Type | Description |
|----------|------|-------------|
| All previous | - | All mechanics continue |
| Increased intensity | - | Faster ability rotations |
| Sisters return | **Adds** | Chirada and Suparna may respawn |

**Tips:**
- Protect boulders at all costs in Phase 2
- Tank swap when Spiny Plume stacks get high
- Kill Satin Plume first to prevent sleep
- Timing on Spiny Plume death is critical for Shriek survival
- Coordinate add priorities with your party
- This fight has multiple hard checks - communication is key
