The Extreme version of the Ifrit trial. An 8-player encounter requiring precise coordination, tank swaps, and healer positioning. One of the original "big three" ARR Extreme trials.

## Ifrit

### Key Mechanics Overview

| Mechanic | Type | Description |
|----------|------|-------------|
| Incinerate | **Tankbuster** | Frontal breath applying Suppuration (max HP reduction) - requires tank swaps |
| Searing Wind | **AoE** | Applied to healers - causes periodic explosions, move away from party |
| Eruption | **AoE** | Targets 3 DPS or off-tank, hits three times in succession |
| Infernal Fetters | **AoE** | Links two players - move APART to break the chains |
| Radiant Plume | **AoE** | Covers arena except 2 small safe spots |

### Phase 1 (100% - ~75%)

| Mechanic | Type | Description |
|----------|------|-------------|
| Incinerate | **Cleave** | Frontal cone - tank faces away |
| Vulcan Burst | **Knockback** | PBAoE knockback - stay at range |
| Eruption | **AoE** | Cracks under players - dodge three successive hits |
| Radiant Plume | **AoE** | Inner or outer ring pattern |

### Phase 2 (First Nails)

| Mechanic | Type | Description |
|----------|------|-------------|
| Infernal Nails (x4) | **Adds** | Kill before Hellfire - staggered kills reduce vulnerability stacks |
| Searing Wind | **AoE** | First application to healers - move to designated spot |
| Hellfire | **Raidwide** | First Hellfire - survivable if nails die |

**Nail Strategy:** Kill nails with slight delays between each to prevent vulnerability stacks from overlapping.

### Phase 3 (Crimson Cyclone Phase)

| Mechanic | Type | Description |
|----------|------|-------------|
| Crimson Cyclone | **AoE** | Five images charge clockwise - run through cleared areas |
| Infernal Fetters | **AoE** | Two players linked - move apart to break the chains |

### Phase 4 (Second Nails)

| Mechanic | Type | Description |
|----------|------|-------------|
| Infernal Nails (x4) | **Adds** | Plus one large center nail |
| Large Nail | **DPS Check** | Use caster/ranged Limit Break on center nail |
| Hellfire x2 | **Raidwide** | Second Hellfire cast |

### Phase 5 (Final Push)

| Mechanic | Type | Description |
|----------|------|-------------|
| All mechanics | - | All previous mechanics repeat with increased frequency |
| Hellfire x3, x4 | **Enrage** | Third and fourth Hellfire - must kill before fourth completes |

**Tips:**
- Tank swap after Incinerate debuff application
- Healers with Searing Wind must stay away from the party
- Players with Infernal Fetters must move apart to break the chains
- Stagger nail kills to prevent vulnerability stack overlap
- Save LB for the large center nail in Phase 4
- Fourth Hellfire is the hard enrage
