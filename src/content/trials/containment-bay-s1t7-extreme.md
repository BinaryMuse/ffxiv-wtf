Extreme version of Sephirot featuring the infamous color tower mechanic, precise knockback positioning, and add phase DPS checks. First of the Warring Triad Extremes.

## Sephirot

The Fiend returns with strict phase transitions and mechanics requiring precise color coordination.

### Phase 1 - Opening

| Mechanic | Type | Description |
|----------|------|-------------|
| Tifferet | **Tankbuster** | Heavy tank damage with Magic Vulnerability - tank swap |
| Ein Sof | **AoE** | Expanding circle from center - move away quickly |
| Ratzon | **AoE** | Targeted ground AoEs - keep moving |
| Triple Trial | **Tankbuster** | Three-hit combo requiring heavy mitigation |
| Chesed | **AoE** | Multiple ground circles - dodge marked areas |
| Fiendish Rage | **Raidwide** | Transition to add phase |

**Notes:**
- Tank swap after Tifferet to reset Magic Vulnerability
- Phase ends around 65% HP

### Phase 2 - Add Phase (Storm of Words)

| Mechanic | Type | Description |
|----------|------|-------------|
| Binah | **Adds** | Large add - focus damage |
| Cochma | **Adds** | Multiple smaller adds |
| Storm of Words | **Enrage** | Must kill adds before timer expires |
| Ratzon | **AoE** | Ground AoEs continue during adds |
| Spirit | **AoE** | Line AoEs from add positions |

**Notes:**
- Kill order doesn't strictly matter, but coordinate focus
- Dodge ground AoEs while burning adds
- Failing this DPS check wipes the party

### Phase 3 - Color Phase

| Mechanic | Type | Description |
|----------|------|-------------|
| Yellow Flash | **Mechanic** | Floor flashes yellow - move immediately to avoid damage |
| Da'at | **Spread** | Players get green or orange debuffs |
| Green Debuff | **Mechanic** | Move to FRONT of arena for green positioning |
| Orange Debuff | **Stack** | Move to towers at BACK of arena |
| Pillar of Mercy | **Stack** | Orange towers deal heavy damage - shield and heal |
| Ein Sof Ohr | **Raidwide** | Heavy room-wide damage |

**Notes:**
- **Critical**: Check your debuff color immediately when Da'at is cast
- Green players front, Orange players in towers
- Towers hurt - shields recommended

### Phase 4 - Knockbacks (Yesod)

| Mechanic | Type | Description |
|----------|------|-------------|
| Yesod | **Knockback** | Blue circles indicate knockback origin points |
| Platform Damage | **Mechanic** | Cracked/damaged floor sections hurt to stand on |
| Edge Death | **Mechanic** | No arena walls - falling is instant death |

**Notes:**
- Position to get knocked away from damaged floor
- Use knockback immunity if available
- Don't stand between knockback origin and arena edge

### Phase 5 - Tethers (Life Force)

| Mechanic | Type | Description |
|----------|------|-------------|
| Life Force | **Mechanic** | Green tethers appear - assigned players take them |
| Force Against Might | **Stack** | Tethered players stack in designated area (usually top-left) |
| Earthshaker | **Spread** | Cone AoEs on marked players - spread by role (healers west, DPS east) |
| Da'at | **Spread** | Color mechanics repeat |

### Phase 6 - Final Phase

| Mechanic | Type | Description |
|----------|------|-------------|
| All Previous | - | Mechanics cycle with increasing speed |
| Pillar of Severity | **AoE** | Additional pillar AoEs |
| Enrage | **Enrage** | Hard enrage timer |

**Tips:**
- Pre-assign tether responsibilities and spread positions
- Call out colors during Da'at for coordination
- Tanks should alternate cooldowns for Tifferet swaps
- Use sprint during Yellow Flash for safety
- Healers pre-shield before Ein Sof Ohr
