Face the Ascian Nabriales in an interdimensional rift. This 8-player trial features unique orb absorption mechanics and a dramatic second phase.

## Nabriales

### Phase 1 (100% - 35% HP)

| Mechanic | Type | Description |
|----------|------|-------------|
| Spark | **Tankbuster** | Single-target magic attack on tank |
| Double/Triple | **Tankbuster** | Multiplies Spark damage - have instant heals ready |
| End of Days | **Cleave** | Line AoE applying Suppuration (max HP down, damage up) |

### Orb Phase (~80% HP)

| Mechanic | Type | Description |
|----------|------|-------------|
| Dark Orbs | **AoE** | Red and black orbs move toward Nabriales - absorb to prevent buff |
| Dark IV | **Raidwide** | Damage scales based on orbs Nabriales absorbed |
| Shadow Sprites | **Adds** | Spawn during orb phases - cast Dark II cone AoE |

**Critical Orb Mechanic:**
- Red orbs deal magic damage and apply magic vulnerability
- Black orbs deal physical damage and apply physical vulnerability
- **Alternate between red and black** - same color consecutively stacks vulnerability dangerously

### Phase 2 (~20% HP)

Nabriales creates a portal pulling all players inside. Buff durations multiply by 10x.

| Mechanic | Type | Description |
|----------|------|-------------|
| Comets | **AoE** | Fall across arena - tanks absorb to prevent party damage |
| Aetherial Tear | **DPS Check** | Spawns where first comet lands - destroy within ~60s or wipe |
| Quake III | **Raidwide** | Room-wide AoE damage |

**Tips:**
- Alternate orb colors to avoid stacking vulnerability
- Save melee Limit Break for the Aetherial Tear in Phase 2
- Tanks should position to absorb comets
- Healers keep tank topped during Double/Triple Spark
