The extreme version of the Necron trial. A challenging encounter with numerous mechanics requiring precise execution and coordination.

## Necron

An enhanced version of Necron with additional phases, tighter timing, and more complex mechanic combinations. This fight cannot be unsynced.

### Core Mechanics (Enhanced)

| Mechanic | Type | Description |
|----------|------|-------------|
| Blue Shockwave | **Tankbuster** | Double tankbuster requiring heavy mitigation |
| Fear of Death | **Spread** | Hand bait mechanics - position carefully |
| Cold Grip | **AoE** | Dodge into light-side attacks |
| Memento Mori | **Mechanic** | 6-2 split mechanic - tanks dark, party light |

### Soul Reaping Variations

| Mechanic | Type | Description |
|----------|------|-------------|
| Soul Reaping | **AoE** | Safe spots on sides or middle - watch the tells |
| Fourfold Blight | **Spread** | Pair-based mechanics with Soul Reaping |
| Twofold Blight | **Stack** | Party stack mechanics with Soul Reaping |

### The End's Embrace (Enhanced)

| Mechanic | Type | Description |
|----------|------|-------------|
| End's Embrace | **Spread** | Dropped hand mechanics - position drops carefully |

### Grand Cross (Enhanced)

| Mechanic | Type | Description |
|----------|------|-------------|
| Grand Cross | **AoE** | Rotating AoEs with precise timing |
| Baits | **Mechanic** | Specific bait positions required |
| Tower Phase | **Stack** | Tower soaking with additional mechanics |

### Add Phases

| Mechanic | Type | Description |
|----------|------|-------------|
| Darkness of Eternity | **Adds** | Add phase requiring focused damage |
| Specter of Death | **Mechanic** | Unsafe row mechanics - identify safe lanes |

### Advanced Mechanics

| Mechanic | Type | Description |
|----------|------|-------------|
| Relentless Reaping | **AoE** | Telegraph-based attacks requiring quick reactions |
| Crop Rotation | **Mechanic** | Starting point selection for mechanic resolution |
| Circle of Lives | **AoE** | Donut AoEs with specific safe spots |
| Mass Macabre | **Stack** | Tower mechanics requiring coordination |

**Tips:**
- Master the normal version first - extreme has tighter timing on all mechanics
- Tanks need strong cooldown management for Blue Shockwave
- Learn the safe zone patterns for Soul Reaping variants
- Coordinate tower assignments during Grand Cross
- Rewards 2 Grave Totems per clear - 10 totems for Ageless Weapon exchange
- Guaranteed Necron Card drop
