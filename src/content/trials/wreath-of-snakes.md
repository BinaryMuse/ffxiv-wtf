A trial against Seiryu, the azure dragon of the Four Lords. This fight features sigil mechanics that require players to read visual cues.

## Seiryu

### Phase 1

| Mechanic | Type | Description |
|----------|------|-------------|
| Fifth Element | **Raidwide** | Room-wide AoE damage. Healers prepare. |
| Infirm Soul | **Tankbuster** | Tank buster attack. Use defensive cooldowns. |
| Serpent Descending | **Spread** | Circle AoE markers on 4 players. Spread out to avoid overlapping damage. |
| Kuji-kiri | **AoE** | Grid of line AoEs appears. Stand between the lines to avoid damage. |
| Forbidden Arts | **Stack** | Line stack marker that fires twice. Stack with the marked player in a line. |

**Notes:** Pay attention to the grid patterns during Kuji-kiri.

### Onmyo Sigil Mechanic

| Mechanic | Type | Description |
|----------|------|-------------|
| Yin-Yang Symbol | **AoE** | Seiryu teleports and creates a yin-yang symbol. **Run away**—creates a point-blank AoE. |
| Serpent-Eye Sigil | **AoE** | Seiryu creates a serpent-eye symbol. **Get close**—creates a large AoE with safe zone around Seiryu. |

**Notes:** Watch the symbol that appears to know whether to run away or move close.

### Phase 2

| Mechanic | Type | Description |
|----------|------|-------------|
| Summon Shiki | **Adds** | Summons minions in a fixed sequence. Handle adds while continuing mechanics. |

**Notes:** Adds spawn in a predictable order. Assign DPS to handle them while others focus on Seiryu.
