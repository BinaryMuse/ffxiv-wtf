A trial against the primal Susano, Lord of the Revel, summoned by the Kojin. This fight introduces several mechanics that become more complex in Extreme mode.

## Susano

### Phase 1

| Mechanic | Type | Description |
|----------|------|-------------|
| Assail | **Tankbuster** | Cast after each mechanic set. Tank should use cooldowns. |
| Rasen Kaikyo | **AoE** | All players are targeted with puddles. Run away immediately to avoid damage and debuffs. |
| Churning | **AoE** | Four players receive a debuff. When dice markers appear with 3 seconds remaining, STOP moving and attacking to avoid Lightning Resist Down. |
| Brightstorm | **Knockback** / **Stack** | A player is marked orange, knocked back across the arena, then marked for a stack. Return to group. |
| Thunderhead | **AoE** | Column AoEs spawn from arena edges targeting a player. Bait them away from the group. |

**Notes:** Keep Susano positioned in the center or at the edge of the arena facing outward.

### Phase 2

| Mechanic | Type | Description |
|----------|------|-------------|
| Blade Shadow | **Adds** / **Enrage** | Giant sword appears. Main tank must interact with purple marker and button-mash to shield the raid. DPS must burn down the sword quickly. |
| Shock Orbs | **AoE** | Off-tank should Sprint clockwise through all orbs with mitigation cooldowns to prevent raid damage. |

**Notes:** All players stack in the middle to begin Phase 2. Tanks swap roles after each sword phase.

### Phase 3

| Mechanic | Type | Description |
|----------|------|-------------|
| Stormsplitter | **Tankbuster** | High damage tankbuster requiring tank swaps. |
| Levin Bolt | **Spread** | Purple-marked players run to the opposite side of a black line that appears. |
| Rock Trap | **Adds** | One player becomes trapped in a rock. DPS must focus the rock to free them. |
| Brightstorm | **Knockback** / **Stack** | Orange-marked players run far behind the group to designate the safe zone. |

**Notes:** Tank positioning returns to Phase 1 setup. Be ready for quick tank swaps on Stormsplitter.
