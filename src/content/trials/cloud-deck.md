The final trial of the Sorrow of Werlyt questline, featuring the Diamond Weapon in a midair confrontation aboard The Cloud Deck—a mobile aerial platform.

## Diamond Weapon

### Phase 1

| Mechanic | Type | Description |
|----------|------|-------------|
| Diamond Rain | **Raidwide** | Unavoidable magical raid-wide damage targeting one platform at a time. Split the group across platforms to manage damage. |
| Adamant Purge | **Cleave** | Watch the boss's arm to determine which platform will be destroyed. Teleport to the safe platform before the attack lands. |
| Claw Swipe | **Cleave** | Accompanies Adamant Purge. Avoid the marked platform. |
| Photon Burst | **AoE** | AoE attack requiring movement to safe zones. |
| Auri Arts | **AoE** | Multiple instances of targeted attacks. |
| Diamond Flash | **Stack** | Stack together to split the damage. |
| Homing Laser | **Spread** | Spread out to avoid Magic Vulnerability stacking from overlapping hits. |
| Homing Missile | **Spread** | Additional spread mechanic—don't overlap damage zones. |

**Notes:** The arena consists of multiple platforms. Watch boss animations to know which platform is safe for Adamant Purge.

### Phase 2

| Mechanic | Type | Description |
|----------|------|-------------|
| Code Chi-Xi-Stigma | **AoE** | Initiates Phase 2 with new mechanic patterns. |
| Articulated Bits | **Adds** | Enemies spawn and tether to players. Move far away from tether source to turn tether purple, or you'll die. |
| Auri Cyclone | **Knockback** | Blue knockback circles appear. Use them to help avoid Diamond Shot tethers by positioning for the knockback. |
| Outrage | **Raidwide** | Heavy raid-wide magical damage. Mitigation and healing required. |

**Notes:** Tether mechanics require immediate recognition—move away from the source until the tether changes color.

### Phase 3

| Mechanic | Type | Description |
|----------|------|-------------|
| Combined Mechanics | **AoE** | Phase 1 and 2 mechanics combine with increased intensity. |
| Diamond Shrapnel | **AoE** | Concluding mechanic with AoE patterns. |
| Enrage | **Enrage** | DPS check to defeat Diamond Weapon. |

**Notes:** Players can fall off the platform but will be revived after a short delay. This costs DPS but isn't immediately fatal.
