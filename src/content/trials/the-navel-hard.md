Hard mode version of the Titan trial. Introduces several mechanics that appear throughout the game.

## Titan

The Lord of Crags, primal of the Kobolds. This fight introduces key mechanics that repeat in Extreme and many later fights.

### Phase 1 (100% - 75%)

| Mechanic | Type | Description |
|----------|------|-------------|
| Rock Buster | **Tankbuster** | Heavy physical damage on main tank - use cooldowns |
| Tumult | **Raidwide** | Multiple hits of party-wide damage - healers prepare |
| Landslide | **Cleave** | Long rectangular AoE knockback - will knock off platform |
| Weight of the Land | **AoE** | Circular AoEs under random players - move out |

### Phase 2 (Heart Phase)

| Mechanic | Type | Description |
|----------|------|-------------|
| Geocrush | **Raidwide** | Jump to center dealing proximity damage - run to edge |
| Granite Gaol | **Adds** | Imprisons a player in stone - destroy to free them |
| Titan's Heart | **DPS Check** | Must destroy heart before enrage |

**Notes:** 
- Stay near edge during Geocrush but not so close you fall off
- Prioritize freeing gaol'd players
- Use LB on heart if needed

### Phase 3 (75% - 0%)

| Mechanic | Type | Description |
|----------|------|-------------|
| All previous | - | All Phase 1 mechanics continue |
| Bomb Boulders | **AoE** | Bombs drop on platform - they explode in sequence, find safe spots |
| Mountain Buster | **Tankbuster** | Upgraded tankbuster - requires heavy mitigation |

**Tips:**
- Watch the order bombs drop - first to land explode first
- Tank should use invuln or heavy cooldowns for Mountain Buster
- Healers should top party before Tumult casts
- Never stand near platform edge except during Geocrush
