A unique trial fought on a floating island against the primal Bismarck. Players must manage island integrity while defeating the whale-like primal.

## Bismarck

This encounter features special interactive objects and a multi-phase structure requiring coordination to board and damage the boss.

### Phase 1 - Chitin Carapace

| Mechanic | Type | Description |
|----------|------|-------------|
| Island Slam | **Raidwide** | Bismarck slams the island, stunning all players and reducing integrity |
| Add Wave | **Adds** | Defeat adds to ready the Dragonkillers |
| Dragonkillers | **Mechanic** | Fire both (north and south) when message appears to chain Bismarck |
| Chitin Carapace | **DPS Check** | Jump onto Bismarck's back to attack - cannot damage from range |
| Whaleback DoT | **Raidwide** | All players on Bismarck take continuous damage - healers use AoE regen |

**Notes:**
- Players must physically jump onto Bismarck's back after harpooning him
- Repeat the harpoon/jump cycle until the Carapace is destroyed
- Healers should prepare HoT effects before jumping onto Bismarck

### Phase 2 - Sanuwa Phase

| Mechanic | Type | Description |
|----------|------|-------------|
| Ul'Sanuwa | **Adds** | Must be tanked - keep separated from So'Sanuwa |
| So'Sanuwa | **Adds** | Must be tanked - keep separated from Ul'Sanuwa |
| Vulnerability Buff | **Mechanic** | If adds are too close, they gain damage reduction - **tank on opposite ends** |
| Tornadoes | **AoE** | Small tornadoes move around arena - being hit launches players |
| Breach Blast | **Raidwide** | High damage if adds survive too long |

**Notes:**
- Assign one tank to each Sanuwa at opposite ends of the arena
- Avoid tornadoes while fighting adds
- The Field Generator is destroyed after this phase

### Phase 3 - Corona

| Mechanic | Type | Description |
|----------|------|-------------|
| Add Wave | **Adds** | More adds spawn - defeat to ready Dragonkillers again |
| Corona Attack | **DPS Check** | Jump onto Bismarck and attack the Corona |
| Island Integrity | **Enrage** | If integrity reaches 0, the party wipes |

**Tips:**
- Magitek Field Generator (center) shields the island from dive damage - use when Bismarck dives below
- Monitor island integrity throughout the fight
- Coordinate Dragonkiller timing - both must fire simultaneously
