A Dawntrail trial featuring Necron, a terrifying entity encountered in the MSQ "The Promise of Tomorrow." The fight takes place in the Lightless Abyss.

## Necron

Necron is a dark entity that splits between light and dark forms, using fear-based mechanics and requiring careful positioning for split mechanics.

### Core Mechanics

| Mechanic | Type | Description |
|----------|------|-------------|
| Blue Shockwave | **Tankbuster** | Heavy tank cleave - tanks position in corners while others stack center |
| Fear of Death | **Spread** | Raidwide AoE spawning 8 purple puddles with hand attacks - spread and bait line AoEs away |
| Cold Grip | **AoE** | Glowing purple arena sides become dangerous - dodge away from glowing edges |

### Memento Mori

| Mechanic | Type | Description |
|----------|------|-------------|
| Memento Mori | **Mechanic** | Boss splits into light and dark sides |
| Dark Side | **Stack** | Tanks go to dark side - only fits 2 players |
| Light Side | **Stack** | Everyone else goes to light side - fits 6 players |

### Soul Reaping

| Mechanic | Type | Description |
|----------|------|-------------|
| Soul Reaping | **AoE** | Four safe zones possible: out, in, sides, or middle |
| Follow-up | **Mechanic** | Observe first cast to determine if next uses partner pairs or light party stacks |

### The End's Embrace

| Mechanic | Type | Description |
|----------|------|-------------|
| The End's Embrace | **Spread** | Fear of Death into spread AoEs dropping hands - dodge telegraphed attacks |

### Grand Cross

| Mechanic | Type | Description |
|----------|------|-------------|
| Grand Cross | **AoE** | Donut AoE requiring mid-stack |
| Arena Shrinkage | **Mechanic** | Arena shrinks during this phase |
| Spinning Lasers | **AoE** | Rotating laser attacks to dodge |
| Tower Soaks | **Stack** | Towers spawn requiring players to soak |
| Spread AoEs | **Spread** | Spread markers appear during tower phase |

**Tips:**
- Remember 6-2 split for Memento Mori - tanks go dark, everyone else goes light
- Watch the edges during Cold Grip - glowing sides are dangerous
- Bait hand attacks away from the group during Fear of Death
- Falling off or getting hit applies Vulnerability Up stacking debuff
