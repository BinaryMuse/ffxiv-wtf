The Extreme version of the Titan trial. An 8-player encounter notorious for its tight execution requirements and punishing knockback mechanics. One of the original "big three" ARR Extreme trials.

## Titan

### Positioning

Everyone except tanks should stack directly behind Titan for healing efficiency. Use the edge as a reference point for dodging.

### Phase 1 (100% - ~85%)

| Mechanic | Type | Description |
|----------|------|-------------|
| Rock Buster | **Tankbuster** | Frontal cleave - tank faces away |
| Tumult | **Raidwide** | Multiple stomps - healers prepare |
| Landslide | **Cleave** | Line AoE with knockback - instant death if knocked off |
| Weight of the Land | **AoE** | Puddles under players - stack and dodge together |
| Mountain Buster | **Tankbuster** | Frontal cone with stacking debuff - tank swap after 2-3 stacks |

### Phase 2 (First Jump)

| Mechanic | Type | Description |
|----------|------|-------------|
| Geocrush | **Raidwide** | Proximity AoE - stand on edge but not too far |
| Granite Gaol | **Adds** | Traps one DPS and one healer - specific positioning required |
| Bomb Boulders | **AoE** | Explode in drop order - move to first bomb location after it explodes |

**Gaol Strategy:** DPS stand under Titan (gaol drops there). Healer runs to far edge to avoid the yellow tether line.

### Phase 3 (Heart Phase - 55% HP)

| Mechanic | Type | Description |
|----------|------|-------------|
| Titan's Heart | **DPS Check** | Must destroy before third Weight of the Land |
| Landslide x5 | **Cleave** | Five-direction Landslide pattern |
| Earthen Fury | **Enrage** | Instant wipe if heart survives |

### Phase 4 (Post-Heart)

| Mechanic | Type | Description |
|----------|------|-------------|
| Granite Gaolers | **Adds** | Must kill while handling other mechanics |
| Clockwork Bombs | **AoE** | Additional bomb pattern - find safe spots |
| Upheaval | **Knockback** | Knockback from center - stay close to Titan |
| All previous | - | All mechanics continue with increased intensity |

### Triple Landslide Pattern

In later phases, Landslide goes in three directions simultaneously. Position to dodge all three lanes.

**Tips:**
- Stack behind Titan for efficient healing
- Many groups move as one unit to dodge Weight of the Land together
- Tank swap after 2-3 Mountain Buster stacks
- Use Party Finder - Duty Finder is not recommended
- Bomb patterns: first to drop = first to explode
- Upheaval knockback can push you off - stay close
