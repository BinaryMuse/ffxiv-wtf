The fourth and final fight of the AAC Light-heavyweight Arcadion raid tier. Wicked Thunder is a former heavyweight fighter with devastating lightning attacks.

## Wicked Thunder

The fight features multiple phases with different attack modes including Gun Mode and Winged Mode.

### Opening Phase

| Mechanic | Type | Description |
|----------|------|-------------|
| Wrath of Zeus | **Raidwide** | Party-wide magical damage requiring healing/shields |
| Wicked Jolt | **Tankbuster** | Line AoE tank buster |
| Sidewise Spark | **Cleave** | Half-arena cleave indicated by which side gathers lightning |
| Shadow's Sabbath | **Adds** | Summons clones that cast Sidewise Spark; later spawns four clones |

### Gun Mode Phase

| Mechanic | Type | Description |
|----------|------|-------------|
| Electrope Edge | **AoE** | Wicked Thunder jumps to arena edge with cannon |
| Threefold Blast | **AoE** | Three sequential blasts covering 75% of arena; only 1×4 column safe. Watch directional indicators |
| Fourfold Blast | **AoE** | Four sequential blasts; dodge into cleared sections |
| Fivefold Blast | **AoE** | Five sequential blasts; increased difficulty |
| Wicked Bolt | **Stack** | Multi-hit stack marker (5 hits); party stacks without moving during hits |

### Winged Mode Phase

| Mechanic | Type | Description |
|----------|------|-------------|
| Winged Wicked Thunder | **Raidwide** | Transformation with new attack patterns |
| Laser Attacks | **AoE** | Vertical cuts through arena tiles instead of horizontal cleaves |

### Follow-up Attacks

| Mechanic | Type | Description |
|----------|------|-------------|
| Thunderslam | **AoE** | Circle AoE baits on players |
| Thunderstorm | **Spread** | Spread markers on players |

### Tips

- Watch which side of Wicked Thunder gathers lightning for Sidewise Spark
- During Gun Mode, only a narrow 1×4 column is safe—watch blast indicators carefully
- Do not move during Wicked Bolt's 5 hits or you'll cause early explosions
- Shadow clones use the same mechanics as the boss—track all sources
- Winged Mode changes the attack axis from horizontal to vertical
- Coordinate party position during multi-blast mechanics
