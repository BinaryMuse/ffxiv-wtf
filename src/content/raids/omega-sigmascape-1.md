The first floor of Omega: Sigmascape, featuring the Phantom Train from Final Fantasy VI. A ghostly locomotive encounter with add phases and unique spotlight mechanics.

## Phantom Train

A sentient ghost train that uses spectral attacks and transports players to alternate arenas.

| Mechanic | Type | Description |
|----------|------|-------------|
| Doomstrike | **Tankbuster** | Moderate tank buster - use cooldowns |
| Head On | **Knockback** | Proximity AoE with knockback - run to opposite side of arena |
| Diabolical Headlight | **Stack** | One player marked with line marker - all others stack between them and boss |
| Diabolical Wind | **Spread** | Green markers on players - spread out to avoid overlapping tornado AoEs |
| Diabolical Light | **Spread** | Two red markers - run to back corners to drop proximity AoEs safely |
| Spotlight | **AoE** | Targeted player gets spotlight AoE - use it to destroy ghosts around arena |
| Diabolical Whistle I | **Adds** | Ghosts spawn and tether to players - if caught, fight add in Passenger Car |
| Diabolical Whistle II | **AoE** | Ghost lines travel across arena from sides - weave between them |
| Ghost Touch | **AoE** | Touching any ghost sends you to Passenger Car to fight an add |
| Passenger Car | **Adds** | Separate arena with add - kill it to return to main fight |

**Strategy:**
- Avoid touching ghosts unless you have the spotlight to destroy them
- For Head On, run to the opposite end immediately for minimum proximity damage
- During Diabolical Headlight, form a line between marked player and boss
- Spread for green markers, corners for red markers
- If sent to Passenger Car, kill the add quickly to return

**Notes:** The fight is about managing ghost spawns while handling positional mechanics. Spotlighted players should actively use their AoE to clear ghosts for the group.
