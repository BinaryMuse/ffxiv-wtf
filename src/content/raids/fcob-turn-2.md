The second turn of the Final Coil features Kaliya, a multi-headed mechanical serpent with complex tether and nerve gas mechanics.

## Kaliya

A three-phase fight with add management and tether mechanics in the final phase.

### Phase 1 (100% - 60%)

| Mechanic | Type | Description |
|----------|------|-------------|
| Double Frontal Cleave | **Cleave** | Two-hit combo shared between both tanks - double tank recommended |
| Nerve Gas | **AoE** | Covers 1/3 of arena with damaging ground effect + Vulnerability Up |
| Secondary Head | **Tankbuster** | Tank swap required - debuffed tank dies instantly from primary head |
| Barofield | **AoE** | At 90% HP - dangerous field around Kaliya preventing passage |

**Nerve Gas Strategy:**
- Always occurs in sets of 3
- After the third cast, expect the frontal cleave
- Avoid standing in the affected areas

**Secondary Head Strategy:**
- Tank swap mechanic
- Off-tank should Provoke during the cast
- Debuffed tank will die instantly if hit by primary head attack

### Stack and Split Missiles

| Mechanic | Type | Description |
|----------|------|-------------|
| Stack Missiles | **Stack** | Requires 3-4 players to group together |
| Split Missiles | **Spread** | Requires players to spread out |

**Missile Strategy:**
- Fires after each Nerve Gas rotation
- Listen for sound effect and watch for visual markers
- Identify which type comes first and react accordingly

### Phase 2 - Add Phase (60% - ~30%)

| Mechanic | Type | Description |
|----------|------|-------------|
| Cube Construct | **Adds** | One of three constructs spawning |
| Ball Construct | **Adds** | Kill at roughly same time as Cube |
| Egg Construct | **Adds** | Kill before phase ends |

**Add Phase Strategy:**
- Phase lasts approximately 2 minutes 30 seconds regardless of progress
- Kill Ball and Cube at roughly the same time
- Kill Egg before phase ends
- Keep all three shapes separated - don't let them near each other
- Prepare for massive AoE damage during phase transition

### Phase 3 - Final Phase (~30%)

| Mechanic | Type | Description |
|----------|------|-------------|
| Construct Detonation | **Raidwide** | Three constructs detonate at phase start |
| Nerve Cloud | **Raidwide** | Massive raid-wide damage following detonation |
| Nanospore Jets | **Spread** | Tether mechanic pairing characters together |

**Nanospore Jets (Tethers) Strategy:**
- Pairs of characters get tethered together
- Too far apart = Vulnerability Up
- Separated further = instant death for both
- If one tethered character dies, partner dies automatically
- Crossing paths with other tethered pairs = Vulnerability Up stacks for all

**Notes:**
- Double tank strategy recommended for frontal cleaves
- Mitigate heavily during phase transitions
- Tethered pairs must move carefully to avoid crossing
- Nerve Gas and seed mechanics continue throughout Phase 3
