The grand finale of the Coils of Bahamut, featuring Bahamut Prime himself. This legendary encounter concludes the story of the Seventh Umbral Era.

## Bahamut Prime

The ultimate challenge of A Realm Reborn, requiring mastery of all mechanics across multiple phases.

### Phase 1 - Opening (100% - 75%)

Rotation: Megaflare + Flame Breath → Flatten + Flame Breath (×3) → Earthshaker → Repeat

| Mechanic | Type | Description |
|----------|------|-------------|
| Flame Breath | **Cleave** | Massive elemental cleave - occurs repeatedly throughout fight |
| Flatten | **Tankbuster** | Heavy tankbuster following Flame Breath - requires cooldowns |
| Earthshaker | **AoE** | Targeted AoE on random players |
| Megaflare | **Raidwide** | Major raid-wide damage signaling phase changes |

**Flatten Strategy:**
- Always follows a Flame Breath, then 3 more Flame Breaths follow
- Tank must be healthy going into this - preceding Flame Breath can be lethal
- Use heavy cooldowns and healer shields (Stoneskin, Adloquium)

### Gigaflare Transition (75%)

| Mechanic | Type | Description |
|----------|------|-------------|
| Gigaflare | **Raidwide** | Extreme raid-wide damage signaling phase change |

**Gigaflare Strategy:**
- Get everyone to full health before 75%
- Use Cure III, Succor, Sacred Soil
- Save Scholar's Virus for this attack
- Heavy mitigation required

### Phase 2 - Divebombs

| Mechanic | Type | Description |
|----------|------|-------------|
| Divebombs | **AoE** | Dragons dive across the arena in sequence |
| Megaflare | **Stack** | Stack markers requiring groups |
| Earthshaker | **AoE** | Targeted ground AoEs |

**Divebomb Strategy:**
- Watch for dive markers and avoid the paths
- Coordinate positioning with stack mechanics
- Bahamut may combine Divebombs with other mechanics

### Phase 3 - Adds

| Mechanic | Type | Description |
|----------|------|-------------|
| Add Phase | **Adds** | Multiple adds spawn requiring coordinated DPS |
| Teraflare | **Enrage** | Wipe if adds not killed in time |

### Phase 4 - Final Phase

| Mechanic | Type | Description |
|----------|------|-------------|
| Akh Morn | **Stack** | Multi-hit stack requiring entire party to share damage |
| Gigaflare | **Raidwide** | Continues from earlier phases |
| All Previous Mechanics | **Various** | Combination of all earlier mechanics |

**Akh Morn Strategy:**
- Multi-hit stack marker
- Entire party must stack to survive
- Hits increase in number as fight progresses
- Heavy healing and mitigation required between hits

**Notes:**
- This is the most challenging fight in A Realm Reborn
- Extensive practice required for each phase
- Coordination between all party members is essential
- Completing this fight concludes the Binding Coil storyline
- Recommended to use Party Finder rather than Duty Finder
- Does not appear in duty roulettes
