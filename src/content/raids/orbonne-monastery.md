The third and final 24-man alliance raid in the Return to Ivalice series. Features characters and mechanics from Final Fantasy Tactics, culminating in the battle against Ultima, the High Seraph.

## Mustadio

The machinist from FFT, using gun-based attacks and mechanical adds.

| Mechanic | Type | Description |
|----------|------|-------------|
| Arm Shot | **Tankbuster** | Tank buster on primary target |
| Energy Burst | **Raidwide** | Group-wide AoE damage |
| Maintenance | **Adds** | Adds repair in large squares - avoid repaired add zones |
| Analysis | **AoE** | Circle marker with gap - face gap toward boss |
| Last Testament | **AoE** | Circle marker with gap - face gap toward boss |

**Strategy:**
- During Analysis/Last Testament, orient your circle marker gap toward the boss
- Avoid standing in squares where adds are being repaired
- Simple fight compared to later bosses

## Agrias

The Holy Knight from FFT, using sword techniques and buff-based mechanics.

### Buff System

Two buff circles appear that grant special abilities:
- **Shieldbearer Circle**: Grants immunity to frontal damage (if you don't move or act)
- **Swordbearer Circle**: Grants special attack against shielded enemies

| Mechanic | Type | Description |
|----------|------|-------------|
| Divine Light | **Raidwide** | Group-wide AoE damage |
| Judgement Blade | **AoE** | Move to Shieldbearer circle and use Holy Shield duty action |
| Cleansing Strike | **AoE** | Move to Swordbearer circle; enemies vulnerable to Holy Sword duty action |
| Hallowed Bolt | **AoE** | Lightning-based AoE attack |
| Mortal Blow (Add) | **Adds** | Use shield action, then grab Swordbearer buff and kill adds |
| Dark Circles | **Stack** | 3 players must stand in each dark circle |

**Strategy:**
- Learn when to use Shieldbearer vs Swordbearer circles
- Judgement Blade = Shieldbearer + Holy Shield
- Cleansing Strike = Swordbearer + Holy Sword
- Coordinate with alliance for add phase

## Thunder God Cid

Cidolfus Orlandeau, the legendary Thunder God from FFT. Complex multi-platform fight.

### Platform Positioning

Each alliance occupies a platform. "Bad stuff" typically goes clockwise (left). Coordinate with your alliance on strategy.

| Mechanic | Type | Description |
|----------|------|-------------|
| Auto-attacks | **Tankbuster** | Hits highest enmity member of EACH alliance |
| Coliseum | **Raidwide** | Group-wide AoE damage |
| Cleansing Strike | **Raidwide** | Reduces HP to 1 until healed to full |

### T.G. Holy Sword Variations

Watch the sword's position to determine safe zones:

| Sword Position | Action |
|----------------|--------|
| In Ground | Move close to boss |
| Sideways | Move away from targeted platforms |
| Raised | Move to back of current platform |

### Crush Techniques

| Mechanic | Type | Description |
|----------|------|-------------|
| Crush Helm | **Tankbuster** | Tank buster with removable debuff |
| Crush Armor | **AoE** | Tether appears - pass to non-tank, pass again after being hit |
| Crush Weapon | **AoE** | Keep moving (typically to the left) |

### Shadow Mechanics

| Mechanic | Type | Description |
|----------|------|-------------|
| Shadowblade | **AoE** | Drop on platform to your left; if 2 markers, second goes to back of platform |
| Duskblade | **AoE** | 3 per circle - each alliance handles the circle to their left |

**Strategy:**
- Watch sword position for T.G. Holy Sword safe zones
- Pass Crush Armor tethers appropriately
- Coordinate AoE marker placement with alliance (typically clockwise/left)
- Cleansing Strike requires immediate healing to full HP

## Ultima, the High Seraph

The final boss of Return to Ivalice, an extradimensional being wielding ultimate destructive magick.

### Phase 1

| Mechanic | Type | Description |
|----------|------|-------------|
| Grand Cross | **AoE** | Avoid AoE markers and move to safe squares |
| Demi-Aries | **AoE** | Slow/fast clock squares - stand on slow, move to fast after explosion |
| Holy IV | **Raidwide** | Raid-wide AoE damage |
| Auralight | **AoE** | Various AoE patterns to avoid |

### Phase 2

| Mechanic | Type | Description |
|----------|------|-------------|
| Ultimate Illusion | **Raidwide** | Move inside shield - heavy group-wide AoE |

### Phase 3

| Mechanic | Type | Description |
|----------|------|-------------|
| Redemption | **Tankbuster** | Heavy tank buster |
| Eastward/Westward March | **AoE** | Line AoEs move in indicated direction - position accordingly |
| Demi-Virgo | **AoE** | Follow circles with arrows and stand at final point to prevent adds |
| Tether | **AoE** | Intercept tether to gain increased damage buff |
| Cataclysm | **Raidwide** | Heavy raid-wide damage |

**Strategy:**
- Grand Cross requires quick movement to safe squares
- Demi-Aries uses same clock mechanic as Belias (slow → fast)
- Ultimate Illusion = everyone inside shield
- Intercept tethers for damage buff if possible

**Notes:** The culmination of the Return to Ivalice storyline. Ultima uses mechanics reminiscent of earlier fights plus new patterns. Heavy healing required throughout.
