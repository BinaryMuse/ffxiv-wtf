The first 24-player alliance raid of the Echoes of Vana'diel series. A crossover with Final Fantasy XI, this raid takes you through echoes of Vana'diel's past, facing iconic bosses from that world.

## Prishe of the Distant Chains

Players may fall off the arena. This encounter features fist-based attacks with variable power levels.

| Mechanic | Type | Description |
|----------|------|-------------|
| Banishga | **Raidwide** | Party-wide magical damage |
| Knuckle Sandwich | **AoE** | Watch Prishe's fist glow (1-3 times with "Wait for it..." voice line); determines size of circle AoE from tethered point, followed by donut AoE |
| Nullifying Dropkick | **Tankbuster** | Shared tankbuster stack on main tank; all 3 alliance tanks should stack |
| Banish Storm | **AoE** | Yellow rods spawn with arrows showing circle AoE travel paths |
| Holy | **Spread** | Spread marker AoEs on random players with Light Resistance Down |
| Crystalline Thorns | **AoE** | Spikes cover arena except L-shaped corners and overlapping squares in middle |
| Auroral Uppercut | **Knockback** | Players knocked up and back from Prishe; fist glow determines trajectory strength |
| Banishga IV | **Raidwide + AoE** | Raidwide damage spawning orbs that explode outward or inward |
| Asuran Fists | **Stack** | Multi-hit (8 hits) stack marker tower; all players stack |

**Tips:** Count Prishe's "Wait for it..." voice lines to determine mechanic size. Position for Auroral Uppercut to land on safe tiles during Crystalline Thorns.

## Fafnir the Forgotten

A dragon encounter with animation-based tells and environmental hazards.

| Mechanic | Type | Description |
|----------|------|-------------|
| Dark Matter Blast | **Raidwide** | Magical raidwide damage; spawns dangerous AoE on arena edge |
| Spike Flail | **Cleave** | "Fafnir raises its tail..." - 270° AoE leaving front safe |
| Dragon Breath | **AoE** | "Intense heat radiates..." - Sweeping fire breath donut AoE leaving ring of lava |
| Touchdown | **AoE** | "Fafnir makes ready to land..." - Large point-blank AoE |
| Baleful Breath | **Stack** | Four-hit line stack AoE dealing magical damage |
| Sharp Spike | **Tankbuster** | Telegraphed AoE physical tankbusters on all three tanks |
| Hurricane Wing | **Raidwide** | Nine hits of magical raidwide damage |
| Horrid Roar | **AoE + Spread** | Circle AoEs in random locations plus spread markers |
| Absolute Terror | **AoE** | Fafnir flies to edge; glowing head = frontal line AoE |
| Winged Terror | **AoE** | Fafnir flies to edge; glowing wings = two side line AoEs |

**Notes:** Darter adds spawn and must be killed before they enrage. If Dragon Breath is followed by Touchdown, find where the lava ring will dissipate first to escape.

## The Ark Angels

Five-boss encounter: MR, EV, HM, GK, and TT. Initially only MR, GK, and TT are targetable.

| Mechanic | Type | Description |
|----------|------|-------------|
| The Decisive Battle | **Debuff** | Each alliance receives a color buff matching a boss's color; attack only matching boss |
| Cloudsplitter | **Tankbuster** | MR targets each tank with telegraphed AoE magical tankbuster |
| Meikyo Shisui | **AoE** | GK summons ice lines, expanding flower AoE, and gaze orb |
| Meteor | **Interruptible** | TT incantation that must be interrupted |
| Havoc Spiral | **AoE** | MR spawns rotating conal AoEs followed by radial knockback |
| Dragonfall | **Stack** | GK tethers and jumps on healers with split damage |
| Guillotine | **AoE** | TT expanding AoE leaving rear safe |
| Dominion Slash | **Raidwide + AoE** | EV raidwide summoning light orbs that create pulsating AoEs |
| Utsusemi | **Adds** | HM summons clones that tether players; avoid contact |
| Mijin Gakure | **Enrage** | HM cast; destroy Ark Shield to interrupt |
| Critical Reaver | **Enrage** | When HM reaches critical HP; interrupt the second cast |
| Arrogance Incarnate | **Stack** | EV multi-hit stack marker |

**Notes:** Bosses share health and will balance if one is too low. Color restrictions drop after first phase.

## Shadow Lord

The final boss. Arena surrounded with dangerous AoE.

### Phase One

| Mechanic | Type | Description |
|----------|------|-------------|
| Giga Slash | **Cleave** | "Shadow Lord readies his blade..." - Two sequential sweeping cleaves; watch sword markers |
| Umbra Smash | **AoE** | Four line AoEs spawn at cardinals, cascading outward |
| Flames of Hatred | **Raidwide** | Magical raidwide damage |
| Implosion | **AoE** | Two semicircular telegraphs; one side expands to half-room based on enlarged orb |
| Cthonic Fury | **Arena Change** | Raidwide damage; transforms arena to four circular platforms connected by pathways |
| Dark Nebula | **Knockback** | Horizontal/vertical line indicates bi-directional knockback |
| Echoes of Agony | **Stack** | Multi-hit stack marker (5 hits) |

**Dark Sigils:**
- Circular spawn pointing inward = circle AoEs on platforms (pathways safe)
- Circular spawn pointing outward = donut AoEs (platforms safe)
- Square spawn pointing inward = outside square safe
- Square spawn pointing outward = inside square safe

### Phase Two

Shadow Lord casts Nightfall, equipping armor and gaining Lord Unshadowed buff.

| Mechanic | Type | Description |
|----------|------|-------------|
| Tera Slash | **Raidwide** | Heavy physical damage requiring mitigation; has countdown timer |
| Giga Slash: Nightfall | **Cleave** | Three cleaves instead of two; third hits north or south |
| Shadow Spawn | **Adds** | Summons Lordly Shadow clones that copy mechanics |
| Unbridled Rage | **Tankbuster** | Line AoE physical tankbuster on all 3 tanks |
| Nova | **Spread** | Spread markers following tankbuster |
| Binding Sigil | **AoE** | Three sets of sequential circle AoEs; dodge into first set after it resolves |
| Damning Strikes | **Stack + Towers** | Three stack marker towers; each alliance takes one |
| Doom Arc | **Raidwide** | Heavy magical raidwide with 15s bleed; grants boss Damage Up |

**Tips:** For Phase Two knockbacks, position to ride four sequential knockbacks in rotation. Mitigate Tera Slash heavily.
