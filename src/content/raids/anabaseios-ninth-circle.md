The first encounter of the Anabaseios raid tier. Kokytos, a soul-devouring entity, absorbs different souls throughout the fight to gain new abilities.

## Kokytos

A phase-based fight where the boss absorbs souls from different entities (Mage, Martialist, Beast, Chimera), each granting distinct mechanic sets. The arena features inner and outer rings used for positioning.

### Key Mechanics

| Mechanic | Type | Description |
|----------|------|-------------|
| Gluttony's Augur | **Raidwide** | Heavy party-wide damage - requires mitigation and healing |
| Duality of Death | **Tankbuster** | Tank buster requiring defensive cooldowns |
| Ravening | **AoE** | Boss absorbs a soul, changing its mechanic set for the next phase |
| Archaic Rockbreaker | **AoE** | Ground-based AoE patterns based on absorbed soul |
| Levinstrike Summoning | **AoE** | Lightning-based attacks from Mage soul |
| Scrambled Succession | **AoE** | Sequenced attacks requiring ordered positioning |
| Ascendant Fist | **AoE** | Martial attacks from Martialist soul |
| Chimeric Succession | **AoE** | Combined mechanics from multiple absorbed souls |

### Soul Absorption Phases

The boss absorbs souls in sequence:

**Mage Soul (Used Twice):**
- Grants magic-based attacks
- Levinstrike Summoning creates lightning AoEs
- Watch for ranged magical patterns

**Martialist Soul (Used Once):**
- Grants martial/physical attacks
- Ascendant Fist creates melee-range dangers
- Stay aware of close-range attacks

**Beast Soul (Used Once):**
- Grants bestial attacks
- More aggressive, primal attack patterns

**Chimeric Soul (Used Twice):**
- Combines abilities from Mage and Martialist
- Most complex phase with overlapping mechanics

### Arena Layout

The arena has distinct zones:

1. **Inner ring** - Close to boss, used for certain mechanics
2. **Outer ring** - Arena perimeter, used for spread mechanics
3. **Clock positions** - Tanks N/S, Healers E/W, DPS intercardinals

### Tips

- Assign clock positions before pull for clean positioning
- Split into light parties (1 tank, 1 healer, 2 DPS each)
- Track which soul the boss has absorbed to anticipate mechanics
- Chimeric phases combine patterns - be ready for complexity
- Use inner/outer rings as positioning guides
- Healers prepare for Gluttony's Augur with party mitigation
