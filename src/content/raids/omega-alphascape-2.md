The second floor of Omega: Alphascape, featuring a simulacrum of Midgardsormr created by Omega. The Father of Dragons uses aerial movements to telegraph attacks.

## Midgardsormr

A recreated version of the legendary dragon, using aerial spins and flips to indicate upcoming attacks.

| Mechanic | Type | Description |
|----------|------|-------------|
| Tail End | **Tankbuster** | Heavy tank buster in Phase 3 - use cooldowns |
| Akh Morn | **Stack** | Multi-hit stack marker - all players stack |
| Akh Rhai | **Spread** | AoE markers on players - spread to avoid overlap |
| Exaflare | **AoE** | Traveling line AoEs - move perpendicular to avoid |
| Cauterize | **Cleave** | Dives across arena - avoid standing in front of boss path |
| Northern Cross | **Raidwide** | Group-wide AoE with frozen arena in Phase 3 |

### Ambient Aether System

The boss spins twice to gather aether. The combination of spins determines the attack:

| Movement Pattern | Result | Safe Position |
|-----------------|--------|---------------|
| Spin + Spin | Point Blank AoE | Move away from boss |
| Spin + Flip | Donut AoE | Get close to boss |
| Flip + Flip | Cross AoE | Stand in corners |

**Strategy:**
- Watch the boss's aerial movements carefully - spins and flips telegraph attacks
- Spin + Spin = get away, Spin + Flip = get close, Flip + Flip = corners
- Stack for Akh Morn, spread for Akh Rhai
- Move perpendicular to Exaflare lines to avoid
- In Phase 3, Northern Cross freezes the arena - prepare for movement restrictions

**Notes:** This fight is about reading the boss's body language. The spin/flip combination system takes practice but becomes intuitive. The arena has no death walls, but falling off still kills you.
