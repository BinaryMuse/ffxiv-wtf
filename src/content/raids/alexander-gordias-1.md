The first floor of Alexander: Gordias, introducing players to the mechanical marvel. Features a miniboss gauntlet followed by the Oppressor encounter with add management and coordinated DPS requirements.

## Faust

A quick miniboss encounter before the main fight.

| Mechanic | Type | Description |
|----------|------|-------------|
| Add Waves | **Adds** | Burn down Faust while off-tank holds all other adds |

**Notes:** Simple DPS check - focus Faust while keeping adds controlled.

## Oppressor

The main boss of A1, featuring two phases with increasing complexity.

### Phase 1

| Mechanic | Type | Description |
|----------|------|-------------|
| Frontal Cleave | **Cleave** | Wide cleave - tank faces boss away from raid |
| Resin Bomb | **AoE** | Circular AoE markers - move out |
| Photon Spaser | **AoE** | Column AoE - dodge to the side |
| Gunnery Pod | **Raidwide** | Unavoidable raid-wide damage - heal through |
| Hydrothermal Missile | **Spread** | Red markers on players - spread apart until resolved |
| Emergency Deployment | **Adds** | Adds spawn tethered to players; drop timed puddles when killed |

### Phase 2 (starts at ~90 seconds)

| Mechanic | Type | Description |
|----------|------|-------------|
| Oppressor 0.5 | **Adds** | Second boss spawns - tank away from first boss |
| Proximity Buff | **AoE** | Bosses buff each other if too close - keep separated |
| 3000-Onze Missile | **AoE** | Vertical blue lasers mark bomb locations - kill adds under them to mitigate |
| Quick Landing | **Knockback** | Both bosses leap with proximity markers - run to opposite side |
| Self-Destruct | **Enrage** | If one boss dies while other lives, raid wipes - balance DPS |

**Strategy:**
- Tank Oppressor in the south, facing away from raid
- When Oppressor 0.5 spawns, off-tank grabs it and keeps bosses separated
- DPS both bosses equally to prevent Self-Destruct
- For Quick Landing, run to the opposite side of the arena from proximity markers
- Kill adds underneath the blue laser indicators to reduce bomb damage

**Notes:** The key to this fight is balanced DPS on both bosses. If one dies significantly before the other, the surviving Oppressor will wipe the raid.
