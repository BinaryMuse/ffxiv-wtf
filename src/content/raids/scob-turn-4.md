The climactic finale of the Second Coil features Nael deus Darnus in a challenging four-phase encounter with meteor mechanics and dive attacks.

## Nael deus Darnus

One of ARR's most iconic and challenging fights, testing coordination across multiple complex phases.

### Phase 1 - Meteors

| Mechanic | Type | Description |
|----------|------|-------------|
| Stardust | **AoE** | Random players marked with red (astral) or yellow (umbral) markers |
| Meteor Drop | **AoE** | Meteors fall dealing proximity damage - standing in them = death |
| Ravensclaw | **Tankbuster** | Frontal cone dealing 3,000-4,000 damage to main tank |

**Meteor Strategy:**
- Meteors require minimum 8 yalms distance between them or both explode
- Pre-position around arena using waymarks
- Ranged spread on outer circle
- Melee position left/right of tank's waymark
- Aim to drop exactly 4 meteors in Phase 1

### Dragon Dive Phase

| Mechanic | Type | Description |
|----------|------|-------------|
| Iron Chariot | **Knockback** | Boss jumps to random target with semi-ranged knockback AoE |
| Dalamud Dive | **Tankbuster** | Boss jumps back to main tank dealing 4,000-6,000 damage |
| Thermionic Beam | **Stack** | Stack marker requiring players to group |

**Iron Chariot Strategy:**
- Avoid standing in the middle of the arena
- Boss jumps to random player, knocks back nearby players
- Then returns to main tank with Dalamud Dive

### Phase 2 - Golems

| Mechanic | Type | Description |
|----------|------|-------------|
| Golem Adds | **Adds** | Green, yellow, and red golems spawn |
| Golem Explosion | **AoE** | Golems explode if they reach meteors |

**Golem Strategy:**
- Golems are attracted to specific meteor colors
- Keep golems away from matching meteors
- Kill golems before they can detonate meteors

### Phase 3 - Ghost Phase

| Mechanic | Type | Description |
|----------|------|-------------|
| Ghost of Meracydia | **Adds** | Ghosts spawn around the arena |
| Bahamut's Claw | **Tankbuster** | Multi-hit tankbuster requiring cooldowns |

### Phase 4 - Megaflare

| Mechanic | Type | Description |
|----------|------|-------------|
| Ravensbeak | **Tankbuster** | Instant attack dealing 5,000-6,000 damage |
| Megaflare | **Raidwide** | Major raid-wide damage requiring mitigation |
| Divebombs | **AoE** | Dragons dive across the arena - avoid their paths |

**Notes:**
- This fight requires extensive practice and coordination
- Waymarks are essential for meteor placement
- Tank cooldowns critical for Ravensbeak and Dalamud Dive
- Each phase builds on complexity - master one before moving to the next
