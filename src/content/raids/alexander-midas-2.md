The second floor of Alexander: Midas, featuring four distinct robot boss encounters. Each boss has unique mechanics that players will see again in A8.

## Blaster

The first robot boss, featuring mines and Mind Blast.

| Mechanic | Type | Description |
|----------|------|-------------|
| Mines | **AoE** | Avoid mines scattered around the arena |
| Mirage | **Cleave** | Straight-line attack - don't stand in front of the robot |
| Mind Blast | **Raidwide** | Group-wide AoE - heal through |

## Brawler

A physical-focused robot with telegraphed attacks based on raised weapons.

| Mechanic | Type | Description |
|----------|------|-------------|
| One Cannon Raised | **Tankbuster** | Single target tankbuster - use cooldowns |
| Two Cannons Raised | **Stack** | Stack marker - MT moves to group to share damage |
| Drill | **AoE** | Proximity-based damage - run away from boss |

**Notes:** Watch the boss's raised hand/weapon to predict incoming attacks.

## Swindler

A magic-focused robot with arithmetic-based mechanics.

| Mechanic | Type | Description |
|----------|------|-------------|
| High Arithmeticks | **AoE** | Purple debuff = Stand LOW (ground level) |
| Low Arithmeticks | **AoE** | Red debuff = Stand HIGH (elevated platform) |
| Bio-Arithmeticks | **Raidwide** | Group-wide AoE - heal through |
| Enumeration | **Stack** | Stack with number of players equal to orbs shown |

**Notes:** For Arithmeticks - Purple means Low, Red means High. Getting it wrong applies a debuff.

## Vortexer

A wind and ice-themed robot with knockback mechanics.

| Mechanic | Type | Description |
|----------|------|-------------|
| Super Cyclone | **Knockback** | Position to avoid being knocked into AoEs |
| Water Spout | **AoE** | Water puddles spawn around arena |
| Ice Missile | **AoE** | If marked, drop ice on Water Spout to freeze it |
| Ultraflash | **Gaze** | Hide behind an Ice Block to survive |

**Strategy:**
- When marked with Ice Missile, drop the ice on a Water Spout to create an ice block
- Use ice blocks to hide from Ultraflash
- Position carefully for Super Cyclone knockbacks

**Notes:** These four robots return in simplified form during A8 (Burden of the Son). Learning their mechanics here makes A8 much easier.
