The third floor of Omega: Sigmascape, featuring the Guardian from Final Fantasy VI. A mech boss that loads different "programs" summoning classic FF6 enemies.

## Guardian

A mechanical boss that loads programs from Final Fantasy VI, each featuring unique mechanics and add phases.

| Mechanic | Type | Description |
|----------|------|-------------|
| Arm & Hammer | **Tankbuster** | Heavy tank buster on primary target |
| Diffractive Plasma | **Raidwide** | Raid-wide AoE - heal through |
| Magitek Ray | **AoE** | Column AoE targeting one player - dodge out of path |
| Missile | **AoE** | Red marker with fire damage debuff on one player |
| Arena Edge | **AoE** | Touching arena edge causes paralysis - stay away from barriers |

### Program Variations

**Ultros Program:**
| Mechanic | Type | Description |
|----------|------|-------------|
| Circular AoEs | **AoE** | Under each player - bait together then move |
| Tentacles | **AoE** | Heavy column AoEs from spawned tentacles |
| Ultros | **Adds** | Off-tank picks up Ultros add |
| Chain Cannon | **AoE** | Circular AoE on targeted player |
| Main Cannon | **Knockback** | Proximity AoE - get far away |

**Dadaluma Program:**
| Mechanic | Type | Description |
|----------|------|-------------|
| Knockback | **Knockback** | Stand near boss with back to corner - avoid hitting barrier |
| Chakra Burst | **Stack** | Eight AoEs spawn - one player per AoE |
| Dadaluma | **Adds** | Off-tank picks up add |
| Aura Cannon | **AoE** | Column AoEs to dodge |

**Air Force Program:**
| Mechanic | Type | Description |
|----------|------|-------------|
| Point Blank | **AoE** | AoE around boss - move away |
| Missiles | **AoE** | Travel slowly across arena edges - avoid |
| Bomb Coils | **AoE** | One player stands in brightest glowing loop |
| Air Force | **Adds** | Off-tank picks up add; avoid cone AoE |

**Bibliotaph Program:**
| Mechanic | Type | Description |
|----------|------|-------------|
| Summoning Circles | **Stack** | Three players must stand in each circle to prevent extra adds |
| Bibliotaph | **Adds** | Off-tank picks up add; avoid point blank AoE |

**Strategy:**
- Watch the screens outside the arena to predict which program loads
- Off-tank should always be ready to pick up the program's add
- Each program has unique positioning requirements - learn them individually
- Chakra Burst requires exactly one player per circle

**Notes:** This fight tests awareness of multiple miniboss patterns. The key is recognizing which program is loading and executing its specific mechanics correctly.
