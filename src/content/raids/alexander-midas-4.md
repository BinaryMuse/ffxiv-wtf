The fourth and final floor of Alexander: Midas, featuring the return of all four robots from A6 before the climactic battle against Brute Justice. An intense, multi-phase encounter.

## Phase 1 - Onslaughter

| Mechanic | Type | Description |
|----------|------|-------------|
| Hydrothermal Missile | **Tankbuster** | Heavy tank damage - use cooldowns |
| Megabeam | **Cleave** | Frontal line attack - don't stand in front |
| Perpetual Ray | **AoE** | Increases magic damage taken |
| Discoid | **Stack** | Tethered orbs appear - higher HP players intercept |

## Phase 2 - Brawler & Vortexer

Both robots spawn simultaneously.

| Mechanic | Type | Description |
|----------|------|-------------|
| Tank Split | **Tankbuster** | Tanks split to separate sides |
| Brute Force | **Tankbuster** | Heavy tankbuster from Brawler |
| Single Blaster | **Tankbuster** | Targets tank |
| Double Blaster | **Stack** | Requires stack to share damage |
| Magicked Mark | **Tankbuster** | Additional tankbuster |

## Phase 3 - Swindler & Blaster

Both robots spawn simultaneously.

| Mechanic | Type | Description |
|----------|------|-------------|
| Tank Split | **Tankbuster** | Tanks on separate sides |
| Mind Blast | **Raidwide** | Group-wide AoE - heal through |
| High/Low Arithmeticks | **AoE** | Stand on floor opposite to debuff color (Purple = Low, Red = High) |
| Enumeration | **Stack** | Number of orbs = players needed in circle (rarely seen) |

## Phase 4 - Brute Justice

The combined form of all four robots.

| Mechanic | Type | Description |
|----------|------|-------------|
| Double Rocket Punch | **Tankbuster** | Heavy tankbuster - use cooldowns |
| J Kick | **AoE** | Proximity-based AoE - run away from boss |
| Apocalyptic Ray | **Cleave** | Massive frontal cone - get behind boss |
| Super Jump | **AoE** | Leap attack - avoid landing zone marker |
| Final Punch | **Enrage** | Soft enrage - increasing damage over time |

**Strategy:**
- Phase 1: Tank Onslaughter, intercept Discoid orbs with higher HP players
- Phase 2: Tanks split Brawler and Vortexer to opposite sides
- Phase 3: Tanks split Swindler and Blaster, handle Arithmeticks correctly
- Phase 4: All out DPS on Brute Justice, avoid frontal Apocalyptic Ray
- For J Kick, run away from the boss to reduce damage
- Get behind Brute Justice for Apocalyptic Ray

**Notes:** This fight is a culmination of everything learned in A6. Players familiar with the individual robot mechanics will have an easier time here. The final Brute Justice phase is a DPS race with heavy healing requirements.
