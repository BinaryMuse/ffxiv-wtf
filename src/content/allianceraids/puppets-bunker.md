The second alliance raid in the YoRHa: Dark Apocalypse series. The investigation continues as alliances delve deeper into the machine threat, uncovering more of the connection between worlds.

## 813P-operated Aegis Unit

| Mechanic | Type | Description |
|----------|------|-------------|
| Firing Order: Anti-personnel Laser | **Tankbuster** | Tank buster with splash - spread from tank |
| Maneuver: Beam Cannons | **AoE** | Overlapping cone AoEs - move to fastest-shrinking overlap |
| Firing Order: Surface Laser | **AoE** | Red indicator on random player - that player moves away |
| Support Pod | **AoE** | Pods spawn with various attacks |
| Life's Last Song | **Raidwide** | Heavy alliance-wide damage |
| Maneuver: High-powered Laser | **AoE** | Linear laser requiring positioning |
| Rune Strip | **AoE** | Strips sent at players - use Sprint through blank spots |
| Firing Order: Dual Laser | **AoE** | Double laser attack pattern |

**Strategy:** Alliances fight on separate platforms. Watch for overlapping mechanics from multiple pods.

## Superior Flight Unit

Each alliance fights an individual flight unit simultaneously.

| Mechanic | Type | Description |
|----------|------|-------------|
| High-powered Laser | **AoE** | Linear attack at players - position at outer edge/corner |
| Incendiary Bombing | **Spread** | Marked players place AoE puddles away from party |
| Formation: Sharp Turn | **AoE** | Bosses form triangle - check sword side for safe zone |
| Sliding Swipe | **AoE** | All alliances gather to one safe corner |
| Lethal Revolution | **AoE** | Spinning blade attack |
| Maneuver: Missile Command | **AoE** | Missile barrage across platforms |
| Formation: Air Raid | **AoE** | Combined flight unit attacks |
| Precision Guided Missile | **Stack** | Stack marker - group with party |

**Strategy:** For Formation: Sharp Turn, the laser swords indicate safe zones - inside or outside based on which side they hold weapons.
