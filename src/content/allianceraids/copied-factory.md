The first alliance raid in the YoRHa: Dark Apocalypse series, a collaboration with NieR: Automata. Twenty-four players venture into an abandoned machine factory to investigate mysterious signals.

## Serial-jointed Command Model

| Mechanic | Type | Description |
|----------|------|-------------|
| Clanging Blow | **Tankbuster** | Tank buster - mitigate accordingly |
| Forceful Impact | **Raidwide** | Alliance-wide damage |
| Systematic Siege | **Adds** | Summons units that shoot orbs in specific directions |
| Energy Assault | **Cleave** | Cone attack with slow-moving orbs - dodge and avoid orbs |
| Systematic Targeting | **AoE** | Units target random players - kite to outside |
| Centrifugal Spin | **Knockback** | Knockback - position to sides |
| Sidestriking Spin | **Knockback** | Knockback - position front or back |
| Systematic Airstrike | **AoE** | Robots target conveyor positions - don't stand under them |
| Systematic Suppression | **AoE** | Directional laser beams - find safe quarter sections |
| Energy Bombardment | **AoE** | Three-part orb pattern - position and move through safe zones |

**Notes:** Pay attention to conveyor belt directions and robot positions for Systematic mechanics.

## Hobbes

| Mechanic | Type | Description |
|----------|------|-------------|
| Laser-resistance Test | **Raidwide** | Hits 3-6 times - heavy sustained damage |
| Ring Laser | **AoE** | Positional waves moving toward platform center |
| Short-range Missile | **AoE** | Targeted explosions on platforms |
| Variable Combat Test | **AoE** | Various attack combinations |
| Towerfall | **AoE** | Structures collapse - avoid marked zones |
| Laser Turret | **AoE** | Turrets target players with beams |
| Shockwave | **Knockback** | Knockback from center |

**Strategy:** Each alliance operates on separate platforms. Healers should position on platform edges for cross-alliance healing range.

## 9S-operated Walking Fortress

| Mechanic | Type | Description |
|----------|------|-------------|
| Neutralization | **Tankbuster** | Final boss tank buster |
| Laser Saturation | **Raidwide** | Heavy alliance-wide damage |
| Total Annihilation | **Raidwide** | Massive damage - requires full mitigation |
| Ballistic Impact | **AoE** | Targeted ground explosions |
| Hack Mechanic | **AoE** | 9S "hacks" the arena - platforms shift |
| Anti-personnel Missile | **Spread** | Spread markers - separate |
| Shrapnel Impact | **AoE** | Fragment explosions |
| Marx Impact | **AoE** | Giant arms slam down |
| Revolution | **AoE** | Platform rotation mechanic |

**Strategy:** This fight involves platform management as 9S hacks the arena. Stay aware of which platforms are active and safe.

**Notes:** Drops YoRHa Type-51 gear (iLvl 460), Pod minions, 2B attire coffer, and orchestrion rolls. One gear piece per player per week when current.
