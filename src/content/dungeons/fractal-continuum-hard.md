A return to the Allagan museum, now disturbed by the awakening of a dangerous Ultima Weapon prototype.

## Motherbit

| Mechanic | Type | Description |
|----------|------|-------------|
| Electrochemical Transfer | **AoE** | Revives Magitek Bits that dash around and fire column AoEs |
| Allagan Gravity | **AoE** | Puddle AoE that pulls players who get too close |
| Citadel Buster | **AoE** | Bits line up and fire columns - move BEHIND them |

**Notes:**
- Stay near the boss to quickly identify which direction Bits are facing
- Avoid getting too close to purple gravity puddles - they pull you in
- For Citadel Buster, identify Bit direction and get behind them

## The Ultima Warrior

| Mechanic | Type | Description |
|----------|------|-------------|
| Aetheroplasm | **Tankbuster** | Hits tank and surrounding area - use cooldowns |
| Citadel Buster | **Cleave** | Boss faces random player and fires column - move away |
| Ceruleum Vent | **Raidwide** | Moderate raid-wide damage |
| Primordial Aether | **AoE** | Varies by Primal statue - always followed by stack |
| Mass Aetheroplasm | **Stack** | Stack marker after Primordial Aether |

**Notes:**
- If boss turns to face you, move out of the way immediately
- Primordial Aether changes based on which Primal the boss tethers to:
  - **Zurvan**: Get fire/ice buff, run to matching circle
  - **Sephirot**: Green markers get growing puddles, spread out
  - **Sophia**: Black/white markers must stack with opposite color

## The Ultima Beast

| Mechanic | Type | Description |
|----------|------|-------------|
| Death Spin | **AoE** | Point-blank AoE when boss raises arm - run out |
| Aether Bend | **AoE** | Donut AoE when boss stands up - get inside hitbox |
| Flare Star | **AoE** | Proximity AoE leaving fire puddle - run far away |
| Allagan Gravity | **Spread** | Purple markers get circular AoEs - don't overlap |
| Light Pillar | **AoE** | Growing AoE from center - run through gaps |
| Allagan Flare | **Spread** | Tank gets spread marker - all move far away |
| Demi Ultima | **Raidwide** | Raid-wide damage, becomes enrage at 5% health |
| Forborn Beast | **AoE** | Boss damage buff - kill before it goes off |

**Notes:**
- Watch boss body position: arm raised = point-blank, standing up = donut
- At 5% health, boss casts slower Demi Ultima as enrage - kill before it completes
- Run through gaps in Light Pillar as it expands outward
