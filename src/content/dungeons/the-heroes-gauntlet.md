A journey through three regions of Norvrandt facing spectral Warriors of Light summoned from beyond. Each boss represents a different heroic archetype from other reflections.

## Spectral Thief

| Mechanic | Type | Description |
|----------|------|-------------|
| Spectral Dream | **Tankbuster** | Three-hit combo on tank; use cooldowns |
| Spectral Whirlwind | **Raidwide** | Unavoidable room-wide damage |
| Dash | **AoE** | Boss tethers to ground marker; dashes there with AoE when countdown ends |
| Spectral Gust | **Spread** | All players marked with circle AoEs; spread apart |
| Chicken Knife | **AoE** | Untargetable knives in corners fire repeated line attacks |
| Shadowdash | **AoE** | Boss splits to two tethered locations with AoE at both |
| Coward's Cunning | **Spread** | Line AoEs on all players; spread to avoid overlap |

**Notes:** During Chicken Knife + Shadowdash combo, stack first to consolidate safe space, then spread. Knife line attacks have brief windows between volleys.

## Spectral Necromancer

| Mechanic | Type | Description |
|----------|------|-------------|
| Twisted Touch | **Tankbuster** | High damage on tank; use cooldowns |
| Chaos Storm | **Raidwide** | Damages all players; healers prepare |
| Absolute Dark II | **Cleave** | Large cone attack |
| Necromancy | **Adds** | Four dark circles spawn Necrobomb zombies that tether to players; move away from glowing zombies |
| Dark Deluge | **AoE** | Circle markers in random locations |
| Fell Forces | **AoE** | Large circles leave persistent Bleed puddles |
| Death Throes | **AoE** | Dark-tethered zombies dash to players and explode; spread apart before immobilized |

**Notes:** Two types of zombie mechanics: first has unmarked circles around glowing zombies, second immobilizes then explodes. Spread for the second type.

## Spectral Berserker

| Mechanic | Type | Description |
|----------|------|-------------|
| Beastly Fury | **Raidwide** | Damages all; creates unsafe area around arena edges |
| Wild Anguish | **Stack** | Stack marker on random player; group together |
| Wild Rage | **Knockback** | Circular knockback marker; stay close or use knockback immunity |
| Raging Strike | **Cleave** | Unmarked line attack where boss faces; move behind boss |
| Falling Rocks | **Spread** | Large circle AoEs on players create rock piles; use rocks to hide from follow-up |
| Wild Rampage | **AoE** | Arena-wide attack; only safe in dark crater puddles. Enter craters late to minimize debuff |

**Notes:** Dark craters give "A Bit Berserk" stacks—at 8 stacks you lose control. Enter craters only when necessary and exit quickly. Rock piles provide cover.
