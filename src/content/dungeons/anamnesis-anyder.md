A return to the depths beneath Amaurot, exploring areas previously sealed. Players investigate the remnants of ancient Amaurotine creations and encounter the hostile Ondo queen in her domain.

## Unknown

| Mechanic | Type | Description |
|----------|------|-------------|
| Fetid Fang | **Tankbuster** | High damage on tank; use cooldowns |
| Inscrutability | **Raidwide** | Damages all and inflicts Bleed (cannot Esuna) |
| Scrutiny | **AoE** | Fireballs with circle AoEs plus spinning arrow; arrow indicates cone attack direction when it stops |
| Luminous Ray | **Cleave** | Line attack where boss faces; don't be in front during cast |
| Ectoplasmic Ray | **Stack** | Clone targets player with line stack; all stand in line |
| Clearout | **Cleave** | Cone attack in front of boss |
| Setback | **Cleave** | Cone attack behind boss |
| Plain Weirdness | **Adds** | Clone gains Damage Up; kill it quickly |

**Notes:** During Scrutiny, the arrow slows while pointing opposite to its final direction—reposition when it starts slowing.

## Kyklops

| Mechanic | Type | Description |
|----------|------|-------------|
| The Final Verse | **Raidwide** | Damages all players; healers prepare |
| 2000-Mina Swing | **AoE** | Large circle around boss (unmarked); watch for boss crouching |
| 2000-Mina Swipe | **AoE** | Large frontal cone (unmarked); watch for raised arm |
| Terrible Hammer/Blade | **AoE** | Tiles marked red hammers then blue swords (or vice versa); first color explodes first |
| Raging Glower | **Cleave** | Line attack at random player; don't be in front |
| Open Hearth | **Stack** | Stack marker during tile mechanics; group on second-color tiles |
| Wanderer's Pyre | **Spread** | All players marked during tile mechanics; spread on second-color tiles |
| Eye of the Cyclone | **AoE** | Donut attack (unmarked); move close to boss when crouching |

**Notes:** All attacks are telegraphed by boss animations, not ground markers. Watch body language: crouching = point-blank or donut, raised arm = frontal.

## Rukshs Dheem

| Mechanic | Type | Description |
|----------|------|-------------|
| Bonebreaker | **Tankbuster** | High damage on tank; use cooldowns |
| Seabed Ceremony | **AoE** | Creates water lines; Depth Grip hands emerge and do line attacks |
| Depth Grip | **Cleave** | Hands do line attacks in direction they face; avoid being in front |
| Rising Tide | **AoE** | Cross-shaped attack from boss |
| Command Current | **AoE** | Cone attacks from boss |
| Flying Fount | **Stack** | Stack marker on player; group together |
| Bubbling Grates | **Adds** | Stand on bubbling grates to stop them; unblocked grates spawn Queen's Harpooners |

**Notes:** During Depth Grip, watch hand spawn order—dodge first set then move to that spot to avoid second set. Later Bubbling Grates has hands that kill adds automatically.
