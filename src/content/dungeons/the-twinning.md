A dungeon set within the Crystal Tower, now merged with the Syrcus Trench. Players navigate through Allagan technology gone haywire while investigating the temporal anomalies within.

## Alpha Zaghnal

| Mechanic | Type | Description |
|----------|------|-------------|
| Augurium | **Tankbuster** | High damage on tank; use cooldowns |
| Beastly Roar | **Raidwide** | AoE damage to entire party; healers prepare |
| Forlorn Impact | **AoE** | Circular AoE markers the boss jumps between |
| Charge Eradicated | **AoE** | Numbered markers on players; boss attacks in order |
| Pounce Errant | **AoE** | Boss leaps to random players with circle AoEs |

**Notes:** Avoid letting boss attacks hit containment units on arena sides—they release Beta Zaghnal adds if broken. If adds spawn, tank grabs them quickly.

## Mithridates

| Mechanic | Type | Description |
|----------|------|-------------|
| Laserblade | **Tankbuster** | High damage on tank; use cooldowns |
| Thunder Beam | **Raidwide** | Party-wide lightning damage |
| Electric Discharge | **AoE** | Multiple lightning AoE circles appear |
| Allagan Thunder | **AoE** | Line AoEs across the arena |

**Notes:** This chimera-type boss has mechanically augmented wings that emit lightning attacks. Watch for telegraph patterns on the ground.

## The Tycoon

| Mechanic | Type | Description |
|----------|------|-------------|
| Magicrystal | **Tankbuster** | High damage on tank; use cooldowns |
| Rail Cannon | **Raidwide** | Party-wide damage |
| Magitek Crossray | **AoE** | Cross-shaped laser pattern across arena |
| Defensive Array | **AoE** | Multiple circular AoE patterns |
| Artificial Gravity | **Knockback** | Knockback from center; position accordingly |
| High-Tension Discharger | **AoE** | Sequential AoE patterns requiring movement |

**Notes:** This time-traveling machina resembles Alexander's core. Watch for overlapping laser patterns and be ready to reposition quickly.
