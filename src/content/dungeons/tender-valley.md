An optional level 100 dungeon in Dawntrail, unlocked after completing the main scenario. Located in the desert regions, featuring cactuar-themed encounters.

## Barreltender

| Mechanic | Type | Description |
|----------|------|-------------|
| Barbed Bellow | **Raidwide** | Party-wide AoE damage |
| Tender Fury | **Tankbuster** | Tank buster; use cooldowns |
| Succulent Stomp | **Stack** | Stack marker on random player; group together |
| Heavyweight Needles | **AoE** | Multiple conal AoEs with gaps; cones expand at cast end, so stand in widest gaps. Arena edge spines inflict Bleeding |
| Tender Drop | **AoE** | Cacti fall from sky; flowered/spiked cacti have large AoE, bare cacti have small AoE |
| Barrel Breaker | **Knockback** | Knockback from center coinciding with cacti explosions; aim to get knocked toward bare cacti |
| Prickly Left/Right | **Cleave** | Half-room cleave that expands into wide sweep; only safe zone is narrow cone on opposite side |

**Notes:** During Tender Drop + Barrel Breaker, position to be knocked toward bare cacti (smaller AoE). Watch for the expanding cones during Heavyweight Needles.

## Anthracite

| Mechanic | Type | Description |
|----------|------|-------------|
| Carbonaceous Combustion | **Raidwide** | Party-wide damage requiring mitigation |
| Anthrabomb (Grey) | **AoE** | Three bombs land and expand; find gaps between them |
| Anthrabomb (Yellow) | **AoE** | Bomb shoots into one of four holes, triggering line AoEs from arena vents based on which hole is hit |
| Anthrabomb Combo | **AoE** | Grey and yellow bombs together; avoid both circular and line AoEs |
| Carniflagration | **AoE** | Repeats Anthrabomb combo three times in succession |

**Notes:** Learn which hole triggers which vents—the bomb color tells you which hole it's heading to. During Carniflagration, prepare to dodge multiple overlapping patterns.

## Reapertail

| Mechanic | Type | Description |
|----------|------|-------------|
| Creeping Decay | **Raidwide** | Party-wide magic damage |
| Tail Guillotine | **Tankbuster** | Heavy tank buster |
| Decaying Flesh | **AoE** | Ground-targeted circle AoEs |
| Soul Douse | **Stack** | Stack marker on random player |
| Blighted Sweep | **Cleave** | Wide conal cleave from boss |
| Withering Curse | **Spread** | Spread markers on all players |

**Notes:** Standard boss mechanics—position carefully for cleaves and coordinate stack/spread mechanics with the party.
