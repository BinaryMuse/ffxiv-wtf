Lady Amandine's manor has been further corrupted by darker voidsent. A challenging hard mode with new bosses and mechanics.

## Manor Jester

A voidsent jester that summons butlers and manipulates their corpses.

| Mechanic | Type | Description |
|----------|------|-------------|
| Manor Butlers | **Adds** | Summoned throughout fight - tank should group for AoE |
| Skeleton Resurrection | **Adds** | Purple void AoE resurrects butler skeletons |
| Manor Steward | **Adds** | Forms if too many skeletons pile together |
| Nether Burst | **Raidwide** | Steward uses this for high party damage |
| Void Blizzard | **AoE** | Damage + Slow debuff on random player |
| Void Blizzard III | **Spread** | Circular AoE around targeted player - spread from others |
| Icefall | **AoE** | Creates ice puddles with Frostbite DoT |

**Notes:** 
- Spread out skeleton kills to prevent them from piling up
- If skeletons merge into Manor Steward, prepare for heavy party damage
- Avoid Icefall puddles - they persist and deal damage over time
- Spread apart when targeted by Void Blizzard III

## Ash

A voidsent fought in a room with patterned laser attacks.

| Mechanic | Type | Description |
|----------|------|-------------|
| Paralysis | **AoE** | Randomly paralyzes party members - healer can cleanse |
| Laser Pattern | **AoE** | Room fills with laser-like attacks in a set pattern |

**Notes:** 
- Healer should be ready to cleanse paralysis
- Lasers follow a set pattern - learn it to avoid damage
- Once you learn the pattern, the fight becomes much easier

## Halicarnassus

The final boss, a succubus with add management and a dangerous ultimate attack.

| Mechanic | Type | Description |
|----------|------|-------------|
| Add Spawns | **Adds** | Spawns adds throughout the fight |
| Blood Rain | **Raidwide** | Heavy damage attack tied to add mechanic |
| Void Fire | **AoE** | Fire-based magical attacks |
| Dark Mist | **AoE** | Point-blank AoE around the boss |

**Notes:** 
- One player should focus solely on killing adds
- Warning: Over-DPSing can cause a wipe - if boss reaches ~20% before third add spawns, the add grab triggers Blood Rain at full damage
- Balance DPS on boss with add management to avoid this issue
- Gear check: tank i60+, DPS i65+ recommended
