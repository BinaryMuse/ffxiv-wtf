A dungeon set in the imposing Garlean structure known as the Tower of Babil. Players must ascend through this military installation, confronting its twisted guardians and ultimately facing a manifestation of the Telophoroi's dark ambitions.

## Barnabas

| Mechanic | Type | Description |
|----------|------|-------------|
| Ground and Pound | **AoE** | Line AoE at random player with minimal telegraph; watch boss positioning |
| Dynamic Pound | **AoE** | Line AoE down center with polarity charges. Same charges repel (stay close to line), opposite charges attract (stay far) |
| Dynamic Scrapline | **AoE** | Boss and players receive charges with point-blank AoE. Follow polarity rules, then dodge second untelegraphed PB AoE |
| Shocking Force | **Stack** | Stack marker; group up to split damage |
| Thundercall | **AoE** | Circular AoEs around arena; dodge markers |
| Rolling Scrapline | **AoE** | Standard circular AoEs to dodge |

**Notes:** The key to this fight is understanding the polarity mechanic. Same charges (both + or both -) repel you away, opposite charges attract you toward the source. Position accordingly before the mechanic resolves. Avoid the damaging ring around the arena edge.

## Lugae

| Mechanic | Type | Description |
|----------|------|-------------|
| Magitek Missile | **AoE** | Targeted AoEs on random players; spread and dodge |
| Magitek Ray | **AoE** | Line AoE; move out of the path |
| Magitek Explosive | **AoE** | Summons bombs with plus-shaped AoE explosions |
| Thermal Suppression | **Raidwide** | Room-wide damage; healers prepare |
| Downpour | **AoE** | Inflicts Breathless stacks; use green panel to become Toad and cleanse before 5 stacks |
| Magitek Chakram | **AoE** | Room-wide damage; use purple panel to become Mini and survive |

**Notes:** This fight features transformation mechanics. When Breathless stacks appear, quickly step on the green transformation panel to become a Toad and clear the debuff. When Magitek Chakram is cast, use the purple panel to become Mini.

## Anima

| Mechanic | Type | Description |
|----------|------|-------------|
| Lunar Nail | **AoE** | Summons nails that create AoE zones |
| Phantom Pain | **Raidwide** | Heavy group-wide damage; healers prepare |
| Aetherial Pull | **AoE** | Purple tethers with arrow indicators; move away until tether turns orange |
| Mega Graviton | **AoE** | Large AoE zones; avoid marked areas |
| Pater Patriae | **AoE** | Sequential attacks requiring movement |
| Boundless Pain | **Raidwide** | Heavy group-wide damage |
| Erupting Pain | **AoE** | Ground-targeted explosions; keep moving |

**Notes:** Watch the tether color during Aetherial Pull—purple means you're too close. Move away until the tether changes to orange indicating safe distance.
