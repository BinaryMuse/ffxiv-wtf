The corrupted lighthouse returns with new Illuminati kobold threats and dangerous bomb mechanics.

## Ghrah Luminary

| Mechanic | Type | Description |
|----------|------|-------------|
| Corruption Prey | **AoE** | Marks players with Prey and casts Aetheric Mimicry |
| Spider Transform | **Adds** | Run to a passive mob before cast completes - the mob transforms into an aggressive spider |
| Poison Pools | **AoE** | Killed spiders leave poison pools - move them away from the group before killing |

**Notes:** 
- When marked with Prey, quickly run to a passive mob in the room
- Kill spider adds but position them away from the party first

## 8th Order Patriarch Be Gu

| Mechanic | Type | Description |
|----------|------|-------------|
| Floor Cracks | **AoE** | Creates floor cracks that leak Aether via area attacks |
| Corrupted Gel | **Adds** | Pull and kill these adds directly on the cracks to stop the leaks |
| Alchemy Engines | **Adds** | Purple engines tethered to the boss - destroy immediately |
| Kobold Adds | **Adds** | Additional adds that spawn during the fight |

**Notes:** 
- Positioning is key - kill Corrupted Gel adds on top of floor cracks
- Prioritize destroying Alchemy Engines quickly

## Progenitrix

| Mechanic | Type | Description |
|----------|------|-------------|
| Grey Bombs | **Adds** | Spawns around arena edges - prioritize killing these immediately |
| Lava Bombs | **Adds** | Additional bomb adds to manage |
| Progenitor Phase | **Adds** | After defeating Progenitrix, Progenitor appears with more bombs |
| Remedy Bombs | **Adds** | Blue bombs tethered to Grey bombs - hit Remedy bombs to push them away |

**Notes:** 
- Always prioritize Grey bombs
- In the Progenitor phase, push Remedy bombs away then destroy Grey bombs
