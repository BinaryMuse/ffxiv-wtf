The sixth and final MSQ dungeon of Dawntrail, set in the technological city of Alexandria in Living Memory. The climactic dungeon of the main story.

## Antivirus X

| Mechanic | Type | Description |
|----------|------|-------------|
| Immune Response (Front) | **Cleave** | Cone AoE in front of boss; get behind or to sides |
| Immune Response (270°) | **Cleave** | 270-degree cleave hitting sides and rear; get in front of boss. First cast also creates unsafe edge around arena |
| Foreign Entity Removal | **Adds** | Summons Interferons in U-shape around boss; plus-shaped adds do cross AoEs, circle adds do donut AoEs. Attacks trigger in spawn order |
| Quarantine | **Tankbuster** | Heavy tank buster on highest enmity plus stack marker on another player; tank separate while others stack |

**Notes:** Watch the Interferon shapes carefully—plus means cross-pattern AoE, circle means donut. They activate in spawn order so track which appeared first.

## Amalgam

| Mechanic | Type | Description |
|----------|------|-------------|
| Amalgamight | **Tankbuster** | Heavy physical tank buster |
| Superbolt | **Stack** | Stack marker on random player |
| Disassembly | **Cleave** | Lightning lines cleave half arena diagonally; move to safe half. Later adds spread markers and lightning portals with line AoEs |
| Centralized Current | **Cleave** | Line AoE from boss; move to sides |
| Split Current | **Cleave** | Line AoEs from boss; only front and back are safe |
| Ternary Charge | **AoE** | Ring AoEs expanding from boss that alternate between circle and donut patterns |

**Notes:** For Ternary Charge, watch whether each ring is filled (get out) or hollow (get in). The pattern alternates, requiring constant repositioning.

## Eliminator

| Mechanic | Type | Description |
|----------|------|-------------|
| Disruption | **Raidwide** | Party-wide magic damage |
| Overexposure | **Stack** | Line stack marker; group up behind marked player |
| Partition | **Cleave** | Cleaves half of arena where boss's sword is positioned |
| Reconfigured Partition | **Cleave** | Sword switches sides mid-cast; reposition to newly safe side |
| Subroutine | **AoE** | Boss's hand moves to perform either line or donut AoE centered on random player |
| Terminate | **AoE** | Large AoEs across the arena in sequence |

**Notes:** Watch the sword position during Partition—it indicates which half is dangerous. Reconfigured Partition requires watching for the sword to switch sides mid-ability.
