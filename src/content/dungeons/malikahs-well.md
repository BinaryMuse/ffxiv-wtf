An ancient water source in Amh Araeng that has become corrupted. Players descend into the well's depths to confront the Lightwarden threatening the region's water supply.

## Greater Armadillo

| Mechanic | Type | Description |
|----------|------|-------------|
| Stone Flail | **Tankbuster** | High damage on tank; use cooldowns |
| Rockfall | **AoE** | Multiple circle AoE markers; dodge all |
| Right Round | **Knockback** | Point-blank knockback from boss; move away |
| Flail Smash | **AoE** | Proximity damage then donut AoE; go to edge, then return to center |
| Head Toss | **Stack** | Stack marker on random player; group together |
| Pack Armadillos | **Adds** | Two adds spawn; tank grab them, DPS burn quickly |

**Notes:** The Flail Smash combo requires two movements—first away for proximity damage, then back in to avoid the donut.

## Amphibious Talos

| Mechanic | Type | Description |
|----------|------|-------------|
| Efface | **Tankbuster** | High damage on tank; use cooldowns |
| Wellbore | **AoE** | Large circle AoE centered on boss; move to edge |
| Waterspouts | **AoE** | Four persistent AoE markers create waterspouts; avoid walking through |
| High Pressure | **Knockback** | Pushes all players from boss; position between waterspouts |
| Swift Spill | **Cleave** | Boss rotates with frontal cone; stay behind boss |

**Notes:** During High Pressure, position yourself so the knockback won't push you into any active waterspouts.

## Storge

| Mechanic | Type | Description |
|----------|------|-------------|
| Intestinal Crank | **Raidwide** | Damages all players; healers prepare |
| Heretic's Fork | **AoE** | Cross-shaped AoE from square markers; stand diagonally to squares |
| Breaking Wheel | **AoE** | Donut AoE; stand inside the glowing circle |
| Crystal Nail | **AoE** | Four circle markers around boss; avoid all |
| Censure | **AoE** | Wings spawn at previous marker locations and repeat attacks sequentially before final boss-centered attack |

**Notes:** Censure replays previous attack patterns—remember where the mechanics spawned and be ready to dodge them again in sequence.
